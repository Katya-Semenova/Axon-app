# Контекст продукта AXON (короткая выжимка)

> Для быстрого входа в сессию. Полная версия — `docs/spec.md → ## Продукт`
> (единственный источник правды; при расхождении прав spec.md).

## Что за продукт
**AXON** превращает сырые данные в готовую презентацию: пользователь загружает файл
(CSV/Excel) → ИИ извлекает «editorial insight-карточки» и собирает дата-сеты (графики)
на node-холсте → пользователь правит и складывает слайды → показывает или делится ссылкой.
Слоган: «Your data, in plain English». Ценится «редакторский», журнальный вид —
в отличие от сухих дашбордов.

## Для кого / роли
Основатели, аналитики, консультанты, product/маркетинг — все, кому надо быстро
превратить выгрузку в наглядный показ. Роли в системе: **Гость** (разбор в памяти,
без ИИ) / **Пользователь** (аккаунт, автосейв, ИИ) / **Admin** (read-only админка
по `ADMIN_EMAIL`).

## Где открывают
Веб, десктоп-first (мобильным — заглушка «лучше с десктопа»). Прод: лендинг
`axon-app.ru`, сервис `axon-app.ru/ai-studio` (basePath, ADR-010). Монорепо
`development/`: `apps/app` (сервис, Next 15) + `apps/landing` (Next 16) + `packages/ui`.

## Три режима
**Data (холст)** — граф Insight → Connection → DataSet, AI-чат-рейл, drill-in.
**Slides (слайды)** — слайды из дата-сетов, 8 архетипов, темы деки (deck-wide).
**Present (показ)** — вывод: ссылка `/p/[token]` работает; PDF/PPTX/Interactive — «скоро».

## Что НЕ делаем (v1)
- Реальный разбор PDF/картинок/SQL в инсайты (принимаем файл, но инсайты упрощённые + бейдж Beta).
- Командная работа в реальном времени.
- PWA (решение 2026-06-21: десктоп-инструмент, пушить нечего).
- Правка существующих инсайтов через ИИ-чат (только руками; чат может ПОСТРОИТЬ новый через «Применить»).
