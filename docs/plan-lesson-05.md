# План — Урок 5 «Расширяем сервис» (AI, админка, REST, оповещения)

> Заточено под Axon (сверено со `spec.md`). Урок 5 — надстройки над готовым продуктом Урока 4.
> Правило урока: всё **опционально и индивидуально** — берём только нужное Axon.
> Каждый шаг начинаем с `/new-feature` (разбор → бриф → код).
> Материалы: `lessons/lesson-05-extended/lesson.md` + `prompts/`.

## 🎯 Шаг 1. AI в продукте — ГЛАВНОЕ для Axon
ИИ — ядро ценности («загрузил файл → ИИ достаёт инсайты»). Сейчас инсайты строит движок
**по правилам** (`lib/insight-engine`), чат-рейл — заглушка «ИИ скоро». Шаг 1 делает ИИ настоящим.

**⚠️ НЕ OpenRouter, а GigaChat (Сбер).** `spec.md` (стр. 30) осознанно выбрал GigaChat: аудитория —
Россия, Claude/OpenAI там геоблок + нельзя оплатить. Следуем spec (правило #1). Завести ADR (выбор провайдера).

**Решим через `/new-feature`:** какие фичи — (а) живой чат по данным пользователя, (б) извлечение
инсайтов реальным ИИ вместо правил (тот самый «сменный разъём»), или оба, и что первым. Плюс:
ключ `GIGACHAT_*` (вписывает владелец в файл), API-route, rate-limit `/api/ai/*`, лимит токенов
на пользователя, обработка ошибок/таймаутов в UI.

🔔 Когда ИИ-разбор станет асинхронным — сработает **отложенный триггер уведомлений** (см. бэклог),
тогда вернёмся к центру уведомлений.

## ⚙️ Шаг 2. Админка — ОПЦИОНАЛЬНО
`spec.md` админку/роли не описывает, но есть набросок `docs/screens/admin-users.md`. Для Axon это
была бы **owner-панель** (юзеры/доски/метрики/логи). Полезно, не ядро. Делать после AI, если нужно.

## 🔌 Шаг 3. REST API — СКОРЕЕ ПРОПУСКАЕМ
Интеграций наружу в spec нет. Axon — инструмент презентаций, не дата-платформа. Без конкретной нужды — мимо.

## 📟 Шаг 4. Telegram + uptime — ОПЦИОНАЛЬНО (uptime полезен)
Оповещения владельцу, не продукт. **Uptime-мониторинг `axon-app.ru`** стоит сделать (узнать о падении
первым). Telegram-алерты — бонус.

## 🔒 Шаг 5. Финальный security-check — ДА, в конце
После AI (новые поверхности: prompt-injection, лимиты, секреты GigaChat). Дополнить растущий
`docs/security-checklist.md` и прогнать — как в Уроке 4.
