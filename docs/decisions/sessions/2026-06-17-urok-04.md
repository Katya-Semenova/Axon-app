# Сессия 2026-06-17 — Урок 4 (бэкенд) завершён

## Что сделано (Урок 4)
- **БД:** PostgreSQL + Prisma, схема по PRD, миграции, seed. Доски — JSON-документ (ADR-003).
- **Auth:** Better Auth (email+пароль): регистрация, логин, защита роутов (per-page gate),
  удаление аккаунта, rate-limit, IDOR закрыт (ADR-004).

- **Публичные ссылки:** `ShareLink` + `/p/[token]`, read-only (ADR-007).
