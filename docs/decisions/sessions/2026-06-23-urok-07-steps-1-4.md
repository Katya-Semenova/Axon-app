## Принятые решения
- **Карта app-map — вертикальная (TB), без рамок-областей**, min-width против ужимания на узких
  экранах; режимы Canvas/Slides/Present как узлы-состояния. (Долго итерировали по просьбе пользователя.)
- **Закрепление `_global.md` — оба слоя** (правило + хук); хук «не падающий» (always exit 0), глушилка ~10 мин.
- **Пароль: «показать пароль» (глазик) вместо второго поля** — унифицировать register+reset (в backlog).
- **App Map в сервис под админ-гейтом** + **кастомная 404** — идеи в backlog (код сервиса, после курса).
