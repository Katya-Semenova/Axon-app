## Принятые решения
- **Приставка `/ai-studio` (а не `/app` и не поддомен `app.`)** — соло-проект, один origin → cookie
  входа/языка общие; имя не дублирует «app» в домене и продаёт ИИ-студию. Детали — ADR-010.
- **`BETTER_AUTH_URL` без приставки** (C1) — Better Auth монтирует свой callback на корне, приставка его ломала.
- **navy-700 только для поверхностей (кнопки/баблы), текст остаётся navy-900** — контраст текста не трогаем.
- **Серии графиков на navy-700 — отдельной задачей** (в backlog), не в этой сессии (не размывать диапазон).

## Находки
- Приставка `basePath` протекает в неочевидные места: «сырые» `fetch`, адрес файла аватара,
  ссылка «поделиться» в `PresentExport`, картинки онбординга, ссылка письма сброса. Собрали в `BASE_PATH`.
- Старые аватары в БД хранят путь без `/ai-studio` → на проде не покажутся, перезалить (на свежем проде — мелочь).
- Подтверждена прежняя грабля: **dev-сервер на Mac пользователя не запускаем** — адаптив правили по
  исходнику, визуальная проверка — на проде после деплоя.
