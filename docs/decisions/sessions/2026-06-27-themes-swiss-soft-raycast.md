## Принятые решения
- **Темы независимы от приложения** — приложение остаётся Editorial; тема меняет только деку через `--slide-*`.
- **Swiss-акцент = красный** (volt-лайм — альтернатива позже). **Soft-акцент = лайм** (только подпись-акцент, не заливка графиков — низкий контраст на белом). **Web/Raycast-акцент = фиолет** (по рефам, не золото).
- **Мини-CMS (Вариант Б)** для тем и карты сайта — админ правит контент; крупная фича после трека тем.
- **⚠️ ВЕРДИКТ к концу дня:** цветовой перекраски МАЛО. Темы выглядят одинаково. Нужна глубокая переделка — ШРИФТЫ + ФОРМА графиков.

## Находки
- Деплой = rsync рабочей папки (не git) → push ≠ деплой; коммитить до/после каждого куска.
- Деплой падал не из-за кода, а из-за лимита кучи Node на боксе 1 ГБ (swap уже был, не помогал — V8 не растёт в swap без `--max-old-space-size`).
- Графики красятся **хардкодом** в `ChartRenderer`, а не из темы (heatmap gold→navy) → Swiss «протекает» жёлтым. Чинится только в `ChartRenderer`.
- next/font грузит шрифты в `app/layout.tsx`; кириллица обязательна (заголовки RU) — ограничивает выбор шрифтов.
