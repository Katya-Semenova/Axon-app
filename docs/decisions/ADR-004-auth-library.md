# ADR-004: Библиотека авторизации — Better Auth

## Status
**Принято (2026-06-16).** Реализовано в Уроке 4, Шаг 5: вход по email+паролю,
без подтверждения email (включим на Шаге 6).

## Date
2026-06-16

## Context
- Урок 4, Шаг 5: нужны регистрация/вход/выход. Курс предлагает выбор из двух
  библиотек: **Better Auth** и **NextAuth (Auth.js)**.
- Аудитория РФ; своя БД PostgreSQL + Prisma (см. [ADR-003](ADR-003-data-layer.md)).
  Вход — email+пароль (решено в интервью 2026-06-16). Гостевой режим (из spec.md):
  можно работать без входа; вход нужен для сохранения/шаринга/экспорта.
- Скилл `/new-feature` (его курс рекомендует для сложных фич) в этой среде **не
  установлен** → фичу собрали **линейно** (урок это допускает — промт самодостаточен).
  Уточняющие вопросы (библиотека, email+пароль vs соцсети, подтверждение email,
  гостевой режим) проговорили в чате.

## Decision
**Better Auth.**
- Весь курс (промты, шаги безопасности) построен вокруг Better Auth.
- Отлично ложится на email+пароль + Prisma-адаптер; пароли хешируются (scrypt) —
  в базе только необратимый хеш.
- Современная, меньше трения, чем NextAuth v5 с credentials.

## Alternatives Considered
- **NextAuth (Auth.js):** зрелая и популярная, но v5 с email+паролем капризнее, и
  пришлось бы отклоняться от всех готовых промтов курса. Отклонено.
- **Своя реализация:** хеширование/сессии/защита от атак — слишком рискованно
  писать с нуля (особенно не-разработчику). Отклонено.

## Consequences
- Таблицы `Session` / `Account` / `Verification` (миграция, Шаг 5); конфиг
  `lib/auth.ts`, клиент `lib/auth-client.ts`, роут `app/api/auth/[...all]`.
- Секреты `BETTER_AUTH_SECRET` + `BETTER_AUTH_URL` в `.env.production`.
- Гостевой режим: сохранение в БД — только для вошедших (`BoardSync`); per-user
  доски и «Мои проекты» — Шаг 7.
- Безопасность auth (rate-limit, флаги cookie, user-enumeration) — **Шаг 9**;
  общий security-check — **Шаг 13**. Многоагентного ревью `/new-feature` не делали
  (скилл не установлен) → security закрываем на этих шагах.
- Подтверждение email выключено в v1; включим на Шаге 6 (письма).
