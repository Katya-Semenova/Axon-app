# ADR-013 — Шесть повседневных скиллов разработки («скиллы силы»)

**Дата:** 2026-07-05 · **Статус:** принято · **Урок 7, Задание 11**

## Решение

В `.claude/skills/` добавлены шесть скиллов из финала курса: `/code-explainer`,
`/code-review`, `/debug`, `/deslop`, `/orchestrate-local`, `/continual-learning`.
Решение пользователя 05.07: ставим все шесть. Готовых установочных файлов в материалах
курса не оказалось (`~/.claude/skills/` пуст) — тела скиллов написаны по описаниям
из урока и адаптированы под проект (русский, наши правила docs/rules/, глоссарий,
лимит параллельных агентов из-за истории с dev-серверами).

## Куда положили и почему

Вариант B из урока — в репозиторий (`.claude/skills/`), а не глобально в `~/.claude/`:
едет в git, доступно любому чату проекта. Зарегистрированы в `.claude/skills/_INDEX.md`
(секция «Разработка»).

## Нюансы

- `/code-review`: в свежем Claude Code есть ВСТРОЕННЫЙ скилл с тем же именем
  (уровни low…max + ultra в облаке). Наш — курсовой вариант с пятью линзами под проект
  (security-guidance, spec, rules); для быстрого прогона годится и встроенный.
- `/debug` дополняет ADR-011 (spec→test→код): воспроизводимый баг — сначала красный тест.
- Какие уже пригодились в проекте: пока никакие — поставлены в финале курса, ждут случая.

**IMPL:** `.claude/skills/{code-explainer,code-review,debug,deslop,orchestrate-local,continual-learning}/SKILL.md`, реестр `.claude/skills/_INDEX.md`.
