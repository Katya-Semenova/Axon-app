## Context

После Урока 3 появились новые вводные, меняющие выбор из ADR-001:
- **Аудитория Axon — в основном Россия** (подтверждено).
- Доступность `*.vercel.app` из РФ без VPN — риск (отмечался ещё в ADR-001); оплата Vercel Pro из РФ затруднена.
- v1 требует **реального бэкенда** (аккаунты, БД, хранение) — нужен сервер, где живёт Postgres. Vercel своего сервера не даёт → пришлось бы брать managed-БД за границей (мимо 152-ФЗ и с теми же проблемами оплаты/доступа).
- Урок 4 курса изначально написан под **свой Postgres на VPS** — переезд возвращает Axon на основную колею курса.
- Преподаватель предложил **Selectel**.

## Decision

**Переезжаем приложение + базу с Vercel на российский VPS — Selectel.**
- Приложение упаковывается в **Docker** (Dockerfile + docker-compose), деплоится через **nginx** (reverse-proxy) + **HTTPS** (Certbot).
- **PostgreSQL** — соседним сервисом в том же docker-compose (co-located, в РФ, дёшево). Managed-Postgres у Selectel — позже, если надёжность станет критичной.
- **Свой домен** с DNS, которым управляем сами.
- Миграция **без простоя:** строим новый дом → проверяем → переключаем домен (DNS) → только потом гасим Vercel. Обратимо.

## Почему Selectel и про риск фильтрации

- Selectel — крупный, надёжный росс. провайдер, хорошая поддержка, **свежий IP**.
- ⚠️ **Риск среды:** любой росс. VPS-IP может попасть под фильтр ТСПУ (с этим уже сталкивались на Таймвебе — IP отфильтровали, сервис стал недоступен). Это риск не провайдера, а среды.
- **Защита — архитектурная, не «правильный провайдер»:**
  1. свой **домен** → при фильтрации IP перенаправляем DNS на новый IP за минуты;
  2. **Docker-портативность** → перевозим сервер за часы;
  3. провайдер с быстрой сменой IP и нормальной поддержкой.

## Alternatives Considered

### Остаться на Vercel (ADR-001)
Минусы под новые вводные: доступ/оплата из РФ, нет своего сервера для Postgres, данные за границей. Отклонено.

### Таймвеб
Рабочий росс. провайдер, но уже есть неприятный эпизод с ТСПУ-фильтрацией IP. Начать с чистого листа на Selectel спокойнее. (Сам по себе не исключён.)

### Managed-БД у провайдера сейчас (Yandex/Selectel DBaaS)
Надёжнее (бэкапы/резерв провайдера), но дороже и избыточно на старте. Отложено — переход возможен позже сменой `DATABASE_URL`.

## Consequences

- **Реактивируется пропущенный VPS-трек Урока 3** (рецепты 05 Docker/compose, 07 домен+HTTPS, 08 базовая безопасность) — выполняем отдельной технической сессией.
- **Урок 4** ложится натурально: Postgres — контейнером на этом же VPS (дефолт урока).
- Деплой меняется: вместо «git push → Vercel сам» — сборка/деплой на сервере через `deploy.sh`.
- ADR-001 помечается superseded.
- Перед закладкой деталей — проверить оплату/доступ Selectel из РФ и завести домен.
