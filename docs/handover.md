# Передача проекта — состояние на 2026-07-26

> Записка для человека, который берёт проект в работу. Полстраницы фактов:
> где код, как запустить, что готово и что нарочно выключено.

## Где код

- **Репозиторий:** `git@github.com:Katya-Semenova/Axon-app.git`
- **Актуальна ветка `main`** — совпадает с `feature/highcharts-spike` (обе на одном коммите).
  Клонировать `main`, ветку спайка отдельно тянуть не нужно.
- Лендинг живёт в **соседнем** репозитории `axon-landing` (не внутри этого).
- Переносимый AI-стек (библиотека промтов, скиллы) вынесен в соседнюю папку `../stack` —
  к работе приложения отношения не имеет. См. [ADR-012].

## Как запустить

```
nvm use                      # Node 24, версия зафиксирована в .nvmrc
cd development/apps/app
npm install
npm run dev
```

Монорепо: приложение — `development/apps/app`, лендинг — `development/apps/landing`,
общий UI — `development/packages/ui`.

⚠️ **Один dev-сервер на машину** — правило проекта, не рекомендация.
Причина и порядок — [rules/dev-server.md](rules/dev-server.md).

## Тесты

```
npm run test:all             # Vitest (модульные) + Playwright (сквозные)
npx tsc --noEmit             # проверка типов, должна быть чистой
```

На `git push` автоматически прогоняется `scripts/git-hooks/pre-push`.

## Прод и выкат

- **Прод:** https://axon-app.ru (сервис — `/ai-studio`). VPS **Selectel**, Docker + nginx.
- **Выкат:** `scripts/deploy-remote.sh` — копирует **локальную рабочую папку** на сервер
  (`.git` не копируется). То есть источник выката — машина разработчика, а не GitHub.
- **Доступы к серверу:** файл `.env.deploy` (адрес, логин, пароль, SSH-ключ, домен).
  В git его нет и быть не должно — получить у владельца проекта.
- Порядок выката, миграции БД, откат — [rules/production-safety.md](rules/production-safety.md).
  Боевая база содержит данные реальных людей: `prisma migrate reset` и seed с очисткой запрещены.

## Что нарочно выключено

**Второй движок графиков (Highcharts)** — код в репозитории есть, но не работает:

- переключатель `lib/renderEngine.ts` → `RENDER_ENGINE = "native"`;
- значение `"highcharts"` включает новый движок (`HighchartsRenderer.tsx`);
- **приёмка не пройдена** — по темам оформления не сверено, флаг не включали;
- известная находка: подписи Treemap через `useHTML` создают вложенные `<body>`,
  что ломает снапшоты доступности. Рассматривался переход на SVG-подписи.

Не включать без прогона по всем типам графиков и всем темам деки.
