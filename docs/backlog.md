## Отложенные фичи — НЕ ЗАБЫТЬ сделать
- **Центр уведомлений внутри приложения (in-app).** Колокольчик в шапке со счётчиком +
  страница со списком + настройки типов (`/settings/notifications`). Нужны модели
  `Notification` / `NotificationPreference` (**миграция БД**) и функция `notify`.
  Отложено на Шаге 7 осознанно: в Axon пока мало событий для уведомлений (нет
  совместной работы и долгих фоновых задач). Сделать, когда появятся реальные
  события (например: разбор файла завершён, проект расшарен). Отмечено и в `spec.md`.

- **FSD-структура — расхождение с курсом (опциональный рефактор, НЕ приоритет).**
  Проект собран плоско (без `src/`, без `entities/features/widgets/pages`): `app/` (роуты+страницы),
  `lib/` (логика/данные), `app/components/` (компоненты по экранам). Урок 2
  (`lessons/lesson-02-design/prompts/04-fsd-architecture.md`) предписывает FSD в `src/`. Это
  осознанный выбор (см. `AGENTS.md` «НЕ FSD-шаблон курса»), функционально ничему не мешает.
  Миграция на FSD — большой рефактор без выгоды для рабочего продукта; делать только если нужна
  строгая сверка с курсом, отдельной сессией. Пока промты уроков переводим FSD→Axon по карте:
  `entities`→`lib/types.ts`+`app/actions/`, `features`→`app/components/*`,
  `shared/ui`→`app/components/ui/`, `shared/lib`/`shared/db`→`lib/`, `src/app`→`app/`,
  `src/middleware.ts`→`middleware.ts`.
