## Отложенные фичи — НЕ ЗАБЫТЬ сделать

- **Темы презентации — 5 тем (один трек).**
  Источник правды — `PRESENTATION_THEMES` в `development/apps/app/lib/types.ts`. Тема меняет ВСЮ деку
  (типографика/цвет/радиус/плотность через `--slide-*`). Это **тема презентации**, НЕ оформление самого
  приложения — **приложение остаётся в журнальном (Editorial) стиле**, эта работа его не трогает.
  Целевой набор — 5 тем:
  1. **Editorial** — фирменная журнальная (serif, hairline, radius 0), дефолт. *Есть (`editorial`).*
  2. **Swiss / швейцарский** — **новая, в коде нет.** Сетка, гротеск (Helvetica/Inter), строгий
     минимализм, много воздуха, чёткая типографическая иерархия.
  3. **Web-dashboard → Raycast** — *есть (`web` / `web-light`).* Прокачать до настоящей Raycast-эстетики
     (почти-чёрная база, один акцент = gold, воздух, мягкие тени, чистая типографика) — тёмный + светлый
     под тумблером ☀/🌙 (светлый `web-light` — скрытая плитка под тумблером). Главная стоимость —
     палитра графиков под фон (`ChartRenderer` + `MiniChart`). Эта тема — заход на **Interactive-показ**
     (отдать слайды как живой веб-дашборд): тумблер «Interactive» сейчас СКРЫТ (coming soon).
  4. **Soft** — *есть (`soft`), но переделать.* Пользователь пришлёт **референсы отдельно** → собрать
     настоящий «софтовый» стиль (не текущий Pinterest-заглушка).
  5. **AI-тема «по образцу»** — **отдельная механика, не пресет.** Кнопка «+ по образцу» → загрузка скрина
     (напр. Pinterest) → vision-модель OpenRouter возвращает JSON {палитра, шрифты, радиус, настроение} →
     мапится в `--slide-*` → новая тема встаёт в ряд. Сейчас кнопка СКРЫТА. Ярус 3 — после AI-инфры (см.
     блок «Рерайт режима Slides» ниже).
  **Приоритет/тайминг:** после Урока 7. Web-dashboard/Raycast + Interactive — в первую очередь
  (Interactive = твой приоритет). `DESIGN.md → UIKit → экран`, без хардкода хексов на странице.

  ### Swiss — рефы + черновик токенов (собрано 2026-06-26)

  сетка, крупный гротеск, выключка влево), Nike **Move to Zero** (Ч/Б + кислотный volt-акцент),
  **Minimal+** (Helvetica Neue, серая шкала, геометрия логотипа). *Прочие присланные картинки
  (синие usevisuals, оранжевые SXM, цветные блоки на чёрном) — НЕ Swiss; отложены как кандидаты в
  рефы для Soft / Web-Raycast.*
  **ДНК Swiss:** гротеск (Helvetica Neue / Inter), крупно/жирно/плотный трекинг, выключка влево ·
  максимальный контраст почти-чёрный на белом + серая шкала + ОДИН яркий акцент · видимая модульная
  сетка и hairline-линии · радиус 0 (острые углы) · в графиках один ряд «горит» акцентом, остальные —
  нейтральная серая шкала.
  **Решение по акценту (2026-06-26):** основной — **швейцарский красный `#D72638`**; **volt-лайм
  `#C6F000`** (как Nike) оставлен как альтернатива на этап реализации.
  **Черновик `--slide-*` (обсуждаемо, не финал — токены идут через `DESIGN.md`):**
  - `--slide-bg`: `#FFFFFF` · `--slide-title`: `#0A0A0A` · `--slide-text`: `#444444`
  - `--slide-accent`: `#D72638` (alt: `#C6F000`)
  - `--slide-border`: `#DADADA` (hairline) · `--slide-muted`: `#EFEFEF` · `--slide-axis`: `#CFCFCF`
  - `--slide-radius`: `0px` · `--slide-title-align`: `left` · отступы блока — плотнее Soft, больше воздуха
  - `--slide-font-display` / `--slide-font-body`: гротеск (Inter/Helvetica), БЕЗ serif; `--slide-font-mono`: JetBrains Mono
  - **Палитра графиков (обязательна — иначе серии «выпадут»):** `--slide-series-1` = accent (герой);
    `--slide-series-2…7` = серая шкала `#1A1A1A → #BFBFBF` (нейтральные ряды); `--slide-tm-ink` под светлый фон.

  **Затрагивает:** SEO-мета (title/description ×2 + hreflang + og:locale), sitemap (обе версии),
  адаптив-прогон на обоих языках (RU длиннее EN на 15–30%).

## Инфраструктура — добавить swap + ускорить деплой (наблюдение 2026-06-23)

- **Контекст:** деплой (`deploy.sh` → `docker compose up --build` на боксе 1 ГБ) идёт несколько
  минут. Причины: мало RAM (сборка двух Next-приложений упирается в потолок) + слабый CPU
  дешёвого бокса (компиляция Next — в основном CPU).
- **(а) Swap — страховка от падения, НЕ ускоритель.** Своп = диск как «запасная RAM»; спасает от
  OOM-падения сборки, но диск ~в 100 раз медленнее RAM, поэтому скорость почти не растёт.
  Сначала проверить, есть ли он: на сервере `free -h` и `swapon --show`. Если нет — добавить
  swap-файл (напр. 2 ГБ): `fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile &&
  swapon /swapfile` + строка в `/etc/fstab`. Снизит риск падения сборки на 1-ГБ боксе.
- **(б) Реальное ускорение (отдельно):** собирать образы НЕ на сервере, а заранее (CI / локально)
  и пушить готовый образ в реестр → на сервере только `pull` + `up`. Или хотя бы наладить кэш
  слоёв Docker, чтобы не пересобирать всё с нуля. Это бОльшая работа — отдельным заходом.

- **Жалоба пользователя (2026-06-23):** на холсте слишком много `Stacked Bar` и `Spline Area`.
- **Причина:** авто-подбор по форме данных в ДВУХ местах тянет к этим двум типам:
  правила-движок `pickChartType` (`lib/insight-engine/chart-rules.ts`): дата → `Spline Area`,

- **Spline Area — вариант А (решение 2026-06-23):** оставляем для НАСТОЯЩИХ временных рядов (это честный
  вид для аналитики; «многовато» лечим тем, что сиды перестанут его дублировать), НЕ уводим даты в другие
  типы. То есть Spline Area = последний по приоритету, но для дат остаётся корректным выбором.
- **Затрагивает:** `chart-rules.ts` (правила), `ai-plan.ts` (промпт ИИ — мягко), и **проверить сид**

> часть этой же глобальной переделки, поэтому чинить отдельно сейчас нельзя (столкнёмся).

  золото→кремовый→синий. Цвет текста в клетке (`heatInk`) тоже захардкожен.

  Это часть переделки «темы меняют деку глобально».
- **Тех-загвоздка:** клетки heatmap считаются в JS (интерполяция rgb), поэтому CSS-переменную
  `var(--…)` нельзя просто подставить в смешивание. Два пути:

    (для карт величин — даже чище; для корреляций — хуже).
  - **(Б) сохранить двухцветность:** завести токены `--slide-heat-low/-mid/-high` в каждой теме
    (сторона тем) + в коде читать их через `getComputedStyle` и лерпить как сейчас. Больше работы,
    диверг сохраняется.
- **Файлы:** `app/components/ChartRenderer.tsx` (`HEAT_LOW/MID/HIGH`, `heatFill`, `heatInk`, градиент
  легенды `#hm-grad`) + `app/components/MiniChart.tsx` (мини-heatmap). **Тайминг:** вместе с глобальной
