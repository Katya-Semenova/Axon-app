## Суть в одной фразе
Сейчас экран Slides вываливает внутреннюю терминологию (движки SciChart/Highcharts/D3, два меню Chart › Stacked Bar, пер-слайдовые ручки). Надо **снести лишнее и собрать всё в три зоны = три скоупа**, как нарисовано ниже.

---

## Принцип: три зоны = три скоупа
Место само говорит, на что влияет действие. Подписи «применяется ко всей деке» не нужны.

```
┌─────────────────────────────────────────────┬──────────────────────┐
│  ЭТОТ СЛАЙД (правишь прямо на нём)            │  ВСЯ ПРЕЗЕНТАЦИЯ     │
│                                               │                      │
│   01 / Заголовок ✎            [ Формат ▾ ]    │   ▸ СТИЛЬ            │
│   ───────────────────────────────────────     │   ▸ ДОСТАВКА        │
│   Summary — клик, правишь ✎                    │                      │
│        ┌──────────────────────┐                │                      │
│        │       ГРАФИК          │                │                      │
│        └──────────────────────┘                │                      │
│   Заметки докладчика — клик ✎                  │                      │
├─────────────────────────────────────────────┴──────────────────────┤
│  ЛОТОК  [1][2][3][4]   ← перетащить →                    [ + слайд ] │
└──────────────────────────────────────────────────────────────────────┘
  ↑ центр = этот слайд     ↑ справа = вся дека      ↑ набор слайдов
```

### Зона 1 — ЦЕНТР: этот слайд
Один цельный блок-слайд, всё правится **на месте** по клику:
- `01 / Заголовок` — редактируемый прямо тут (сейчас — только через дата-сет).
- **Summary** — клик, правишь.
- **График** — превью.
- **Заметки докладчика** — клик, правишь.
- Сверху справа на слайде — **одна** кнопка `[ Формат ▾ ]`.

### Зона 2 — ПРАВЫЙ РЕЛЬС: вся дека
Два сворачиваемых блока, оба влияют на всю презентацию:
- **СТИЛЬ** — Дверь 1 (пресеты-темы) + Дверь 2 (AI по образцу). Строго deck-wide, никаких пер-слайдовых ручек.
- **ДОСТАВКА** — Аудитория / Тон / Заметки.

### Зона 3 — НИЗ: лоток
Слайды `[1][2][3][4]`, перетаскивание, `[ + слайд ]` = список готовых дата-сетов, ещё не ставших слайдами (нет данных → ссылка на холст).

### Present-режим
Чистый вывод: формат (ссылка/PDF/PPTX/PNG) + перестановка + показ. Ничего не правится. Перестановка разрешена и в Slides, и в Present.

## Кнопка «Формат» — отдельный разбор

### Почему сейчас сломана (диагноз)
Кнопка просит выбрать из нашей таблицы типов абстрактными словами без картинок. Тестеры просто тыкают наугад. Четыре беды:
1. **Смешаны два уровня** — «График» (категория с 10 видами внутри) стоит в одном ряду с «Большая цифра», «Цитата» (конкретные форматы). «Фрукт рядом с долькой».
2. **Слова про форму, а не результат** — Sentiment / Word List / Lollipop / Spline Area. Человек думает «хочу показать одну цифру», а не «хочу слайд Sentiment».
3. **Нет превью** — нельзя предсказать результат, кроме как кликнуть.
4. **Порядок по базе данных**, а не по смыслу.

### Как чинить — сменить вопрос на «как ты хочешь это показать?», два честных уровня + AI-подсветка

**Шаг 1 — «Как показать этот слайд?»** (крупные плитки с мини-превью, названия про результат):
```
┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐
│ ▁▃▅▂   │  │  82%   │  │ ◐ vs ◑ │  │  " "   │
│ График │  │ Одна   │  │ Срав-  │  │ Цитата │
│        │  │ цифра  │  │ нение  │  │ /текст │
└────────┘  └────────┘  └────────┘  └────────┘
  ✓ AI советует
```

**Шаг 2 — только если выбрал «График» — «Каким графиком?»** (превью на ТВОИХ данных, подпись по смыслу, тех-термин мелким; несовместимые прячем):
```
┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│ ▦▦▦  │ │ ◔    │ │ ▁▃▅  │ │ 🗺   │
│Доли  │ │Доли  │ │Дина- │ │Гео-  │
│целого│ │целого│ │мика  │ │графия│
│Treemap│ │Donut │ │Spline│ │ Map  │
└──────┘ └──────┘ └──────┘ └──────┘
   ✓ AI советует
```

### Два открытых вопроса (решить ПЕРЕД кодом «Формата»)
1. **Sentiment и Список слов** — оставляем / режем / переименовываем по-человечески? (самые непонятные на тестах).
2. **Подписи у графиков** — «по смыслу» (доли целого / динамика / география) ИЛИ технические (Treemap / Donut)?

## Стиль — две двери (правый рельс → СТИЛЬ)

Обе двери дают объект **Theme** (набор `--slide-*` CSS-vars), строго на всю деку.
```
┌───────────────────────────┐
│  СТИЛЬ                     │
│  ┌─────┐ ┌─────┐ ┌─────┐  │   ← Дверь 1: готовые пресеты
│  │ Aa ▆│ │ Aa ▆│ │ Aa ▆│  │     (тыкнул — вся дека сменилась)
│  └─────┘ └─────┘ └─────┘  │
│  Editorial  Soft   Web     │
│  ┌─────┐ ┌─────┐           │
│  │ Aa ▆│ │  +  │           │
│  └─────┘ └─────┘           │
│   Bold   по образцу        │   ← Дверь 2: AI по Пинтересту
│  ─────────────────────────  │
│  ДОСТАВКА                  │
│  Аудитория   [ CEO ▾ ]     │
│  Тон         [ Прямой ▾ ]  │
│  Заметки     [ Speaker ▾ ] │
└───────────────────────────┘
```
- **Дверь 1 (обязательна):** пресеты `PresentationTheme` в `lib/types.ts`. Уже есть: Editorial, Soft, **Web** (тёмная, прототип в рабочем дереве — см. ниже). Добавить: Bold / Minimal / Magazine.
- **Дверь 2 (опциональна):** загрузка скриншота (Пинтерест) → vision-модель OpenRouter (ИИ-слой Урока 5) извлекает палитру/шрифты/вайб → готовая Theme (JSON, как `AIInsightPlan`) → в тот же ряд пресетов.
