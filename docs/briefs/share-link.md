# Бриф: Поделиться презентацией по ссылке (Шаг 12)

> Фича через `/new-feature`. Одобрено 2026-06-17. Заменяет фейковый экспорт-макет
> в режиме «Показ» реальной ссылкой. PDF/PPTX — в бэклоге (отдельные шаги позже).
> Предпосылка выполнена: локальная БД (Neon) поднята и проверена — регистрация/автосейв работают.

## Намерение
Пользователь «финалит» собранную деку как **рабочую публичную ссылку**: жмёт
«Поделиться» в режиме «Показ» → получает адрес вида `/p/<токен>` → отправляет
кому угодно. Получатель **открывает без входа** и видит read-only показ слайдов.
Владелец может **отозвать** ссылку.

## Аудитория и успех (из spec.md)
Основатели / аналитики / консультанты. Успех = из «Показа» получил **настоящую**
ссылку (не фейковый `axon.app/s/…`), открыл её в другом окне/устройстве **без входа**
и увидел свою деку; отозвал — ссылка перестала работать.

## Механика
1. **Создание (за входом, EC-4).** В «Показе» формат «View Link» → «Поделиться»:
   - вошедший с сохранённой доской → создаём `ShareLink(boardId, token)` → показываем `/p/<токен>` + «Скопировать»;
   - гость / несохранённая доска → инлайн-вход (`AuthModal`, Шаг 7b) + сохранение доски (`createProjectFromData`) → затем ссылка.
2. **Публичная страница `/p/[token]`** (новый роут, вход НЕ нужен): по токену находим ShareLink → если не отозвана → грузим `Board.data` → рендерим слайды read-only (листание ←/→, точки, логотип). Экран уже описан — [screens/public-presentation.md](screens/public-presentation.md).
3. **Отзыв.** В «Показе» владелец видит активную ссылку и кнопку «Отозвать» → `revoked = true` → страница отдаёт «Презентация недоступна».

## Данные (миграция)
Новая модель Prisma **`ShareLink`** (согласована со spec → раздел «Данные»):
`id, boardId (→ Board), token (unique), createdAt, revoked (bool)`. Нужна **миграция**
(применим к Neon локально и к проду при деплое). Серверные действия:
`createShareLink(boardId)`, `revokeShareLink(id)`, `getSharedBoard(token)` — владельца
берём из серверной сессии (IDOR-защита, как в board.ts).

## Граница / переиспользуем
- Рендер слайдов read-only — переиспользуем существующий рендер деки (как в «Показе»/`MiniChart`/`ChartRenderer`).
- Вход-гейт и перенос гостя — `AuthModal` + `createProjectFromData` (Шаг 7b).
- Серверная сессия и IDOR-проверки — паттерн из `app/actions/board.ts`.
- Парсинг/движок/холст — не трогаем.

## За рамками (бэклог)
- **PDF и PPTX** экспорт (отдельные шаги — другой механизм: генерация файла).
- **«Сделать копию себе»** получателем (клон деки в свой аккаунт) — на потом.
- Срок жизни/протухание ссылки (пока — бессрочно до отзыва, как в спеке).
- Превью-картинка ссылки (OG-image) для мессенджеров.

## Крайние случаи
- **Невалидный / отозванный / удалённый токен** → «Презентация недоступна» + ссылка на лендинг (не белый экран, не 500).
- **Гость жмёт «Поделиться»** → сперва вход + сохранение доски, потом ссылка.
- **Пустая дека (0 слайдов)** → «Поделиться» недоступно (как сейчас кнопка BUILD).
- **Neon уснул (free-tier)** → первый запрос будит; обработать таймаут мягко (повтор/ретрай), не падать 500.
- **Повторное «Поделиться»** одной доски → переиспользуем активную ссылку (не плодим токены).

## Зависимости
БД (Neon — готово ✅) + миграция ShareLink. Новых внешних сервисов нет.

## Сложность
**COMPLEX** — миграция БД + новый публичный роут + создание/отзыв за входом +
read-only рендер. Локальная проверка теперь возможна (есть Neon). Роли:
исследователь → архитектор → кодер → ревью логики → ревью безопасности → тех-лид.
Вероятен короткий **ADR** на механизм шаринга (токен/отзыв/доступ).

## Чеклист ревью
- Создаётся **настоящая** ссылка; открывается **без входа** в другом окне и показывает деку.
- Отзыв реально выключает ссылку; невалидный токен → «недоступна», не 500/белый экран.
- Создание ссылки — только для владельца из серверной сессии (IDOR-защита); чужую доску расшарить нельзя.
- Гость: вход + сохранение, потом ссылка.
- Публичная страница не светит приватных данных сверх деки (только слайды; не весь холст/чужие проекты).
- `tsc` чист; миграция применяется на Neon и (при деплое) на проде; `spec.md` + `screens/public-presentation.md` обновлены (статус «реализовано»).
