# Бриф — Шаг 8: хранилище файлов + загрузка аватара

> Урок 4, Шаг 8. Процесс: `/new-feature`. Сложность: COMPLEX (новая зависимость + внешний сервис + секреты), **без миграции** (поле `User.image` уже было). Дата: 2026-06-16.

## Намерение
Поднять объектное хранилище и дать первую загрузку файла — **аватар** пользователя (фото в шапке вместо инициалов). Механизм переиспользуемый под будущие файлы.

## Решения (одобрено)
- Хранилище: **Selectel Object Storage** (managed S3) — не грузит маленький VPS, данные в РФ.
- Первый файл: **аватар** (`User.image`).
- Доступ к аватарам: **публичное чтение** (не секрет, проще). Signed URLs + проверка владельца — позже, для секретных исходных файлов.

## Что построено
- `lib/storage.ts` — S3-клиент (`@aws-sdk/client-s3`) из env (`S3_*`), `putObject` + публичная ссылка; без ключей — понятная ошибка.
- `app/api/avatar/route.ts` — POST: проверка сессии (только свой аватар, id из сессии), валидация **по содержимому** (magic bytes PNG/JPEG/WEBP) + лимит 2 МБ; кладёт `avatars/<userId>-<ts>.<ext>`; возвращает ссылку.
- `app/components/ui/Avatar.tsx` — поддержка `src` (картинка вместо инициалов).
- `app/settings/SettingsForm.tsx` — блок «Фото профиля»: текущее фото + загрузка → `authClient.updateUser({ image })` → превью + сообщение.
- `app/components/AuthNav.tsx` — фото в шапке.
- `.env.example` + `docker-compose.yml` — `S3_*`; i18n (Settings namespace).
- `docs`: ADR-006, INDEX, spec, infrastructure.

## Безопасность
- Загрузка только для вошедшего; ключ привязан к `userId` из сессии (свой аватар).
- Проверка типа по байтам (не по MIME), лимит размера. Ключи S3 — только в env на сервере.
- Антиспам загрузок (rate-limit) — Шаг 9.

## От пользователя (как с Resend)
В Selectel: создать Object Storage **bucket** с публичным чтением + ключи доступа; узнать endpoint/регион/публичный URL. Вписать `S3_*` в `.env.production` на сервере.

## Проверки
`tsc` чистый, `next build` успешный (`/api/avatar`, `/settings`). Реальная загрузка — **на проде** после ключей: в «Настройках» выбрать фото → появляется в шапке; чужой аватар поставить нельзя (id из сессии).
