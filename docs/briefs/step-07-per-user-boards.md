# Бриф — Шаг 7: доски по пользователям + «Мои проекты» + IDOR

> Урок 4 (Бэкенд), Шаг 7. Процесс: `/new-feature`. Сложность: **MEDIUM** (5–6 файлов, без миграции БД). Дата: 2026-06-16.

## Намерение
Развести доски по владельцам: каждый вошедший видит и редактирует только свои проекты; чужую доску открыть нельзя. Заменить единственную общую `demo-board` на список реальных проектов пользователя.

## Аудитория / критерии успеха
Роль «Пользователь». Успех: вошёл → видит свой список → создаёт/открывает/переименовывает/удаляет проект → правки автосохраняются в *его* доску; чужой board id отдаёт «не найдено».

## В объёме
1. **IDOR-защита** в `getBoard`/`saveBoard` — серверная проверка `Board.ownerId === session.user.id`.
2. **Новые серверные экшены:** `listProjects`, `createProject` (создаёт доску с пустым `data`), `deleteProject`, `renameProject` — владелец только из серверной сессии.
3. **«Мои проекты»** в дашборде: для вошедшего реальный список (создать/открыть/удалить/переименовать) вместо мок-карточек. Гость — витрина-тизер + работа в памяти.
4. **Привязка воркспейса к board id:** `page.tsx` хранит `currentBoardId`, `BoardSync` грузит/сохраняет именно эту доску. Новый проект при открытии засевается демо-данными.

## За рамками (→ Шаг 7b)
Перенос гостевого холста в аккаунт при регистрации; инлайн-форма входа на «Сохранить/Поделиться/Экспорт».

## Крайние случаи
0 проектов → пустое состояние с «Создать»; чужой/удалённый id → «не найдено»; удаление текущего → назад к списку; гость → всё в памяти, БД не трогаем.

## Файлы
- `app/actions/board.ts` — IDOR + 4 новых экшена (серверная сессия)
- `app/components/BoardSync.tsx` — приём `boardId`, грузить/сохранять по нему, null=гость
- `app/page.tsx` — состояние `currentBoardId`
- `app/components/landing/LandingPage.tsx` — разведение гость/вошедший
- `app/components/landing/MyProjects.tsx` — новый: список «Мои проекты»
- `lib/store.ts` — экспорт `initialBoardData()` (свежий демо-сид нового проекта)
- `lib/types.ts` — тип `ProjectSummary`
- `messages/ru.json`, `messages/en.json` — словарь `Landing.my.*`
- Доки: `docs/spec.md`, `docs/security-todo.md`
