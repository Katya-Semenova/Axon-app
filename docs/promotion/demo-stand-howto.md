# Демо-стенд AXON — шпаргалка (подготовка → показ → уборка)

> Для presentации команде ~11.07 и любых будущих показов «гости со своих телефонов».
> Создано 2026-07-05. Технические детали — `docs/memory/infrastructure.md` (секции «Демо-режим»).

## Как это устроено (в двух словах)

- На странице входа `axon-app.ru/ai-studio/login` есть кнопка **«Попробовать демо»** —
  один тап, и гость внутри БЕЗ регистрации (сервер сам логинит общий аккаунт
  `demo-stand@axon-app.ru`; пароль гостю не виден).
- Деньги на ИИ защищены лимитом: **5 запросов ИИ в час с одного телефона** (по IP),
  гость видит счётчик «осталось N из 5».
- До дня показа всё приложение закрыто временным паролем-замком (`axon` / `1902`,
  строго маленькими буквами) — кнопку видим только мы. Гостям замок не показываем:
  в день показа его снимаем, после — возвращаем.
- Все гости сидят под ОДНИМ аккаунтом: видят один и тот же проект и могут его
  поменять. Это ок для стенда; сломали — восстанавливаем (см. ниже).

## Подготовка (один раз, до дня показа)

1. **Наполнить демо-аккаунт** (сейчас он пустой — гостя встречает «No projects yet»):
   на десктопе открой `axon-app.ru/ai-studio/login` → в сером окошке браузера `axon` / `1902`
   → кнопка «Попробовать демо» → загрузи `test-data/gym-traffic.csv` (даст золотой heatmap)
   → дождись карточек-инсайтов, собери слайды как нравится → при желании добавь
   `test-data/marketing-channels.csv` (treemap/donut/lollipop — разнообразие типов).
2. **QR в презентацию:** картинка `docs/promotion/qr-demo-stand.png`
   (внутри зашита ссылка `https://axon-app.ru/ai-studio/login`).
   Перед печатью/вставкой ПРОВЕРЬ: наведи камеру телефона — должна открыться
   страница «Вход в Axon» (сейчас — после серого окошка с паролем; это норма).
3. **Прогон с телефона:** через замок (`axon`/`1902`) → «Попробовать демо» →
   видно готовый проект, ИИ отвечает, счётчик тикает.

## В день показа (утром, 2 минуты)

1. Снять пароль-замок. Проще всего: сказать Клоду «сними Basic Auth» — или руками по
   инструкции `docs/memory/infrastructure.md`, раздел «🔓 СНЯТЬ пароль».
2. Проверить с телефона: QR → страница входа открывается СРАЗУ, без серого окошка.

## Как рассказывать гостям (скрипт, 20 секунд)

«Наведите камеру на QR-код → откроется страница входа → нажмите **"Попробовать демо"** —
и вы внутри без регистрации. Перед вами живой проект: данные, карточки-выводы, графики,
слайды. Можно задать вопрос ИИ прямо про эти данные — до 5 вопросов в час.
Полная работа со своими файлами — на компьютере.»

## После показа (в тот же день)

1. Вернуть пароль-замок: сказать Клоду «верни Basic Auth» — или руками по инструкции
   (раздел «🔒 ВЕРНУТЬ пароль»). Проверка: `/ai-studio` снова просит логин.
2. Кнопку демо можно НЕ выключать — за замком её никто не видит. Совсем убрать
   (когда сезон показов закончится): на сервере в `.env.production` удалить/поставить
   `NEXT_PUBLIC_DEMO_ENABLED=false` и пересобрать контейнер (это делает Клод).

## Если гости сломали демо-проект

Аккаунт общий — кто-то мог удалить карточки или слайды. Восстановление = подготовка
заново: зайти через «Попробовать демо», удалить испорченный проект, снова загрузить
`gym-traffic.csv` и собрать. 5 минут.

## На какой период это живёт

Постоянно, безопасно: кнопка на проде, но за замком. «Наружу» демо-стенд выходит только
в дни показов — ровно на время между «снять пароль» и «вернуть пароль».

## 🔧 Если Клода нет под рукой — всё то же руками, через Терминал

**Шаг 0 — зайти на сервер.** Данные доступа лежат в файле `.env.deploy` в корне проекта
(в git его нет): `SERVER_IP`, `SERVER_USER`, пароль/ключ. В Терминале на Mac:
```
ssh root@176.114.91.231
```
Если спросит пароль — вводи вслепую (символы не показываются — это нормально) и Enter.
Дальше все команды выполняются НА СЕРВЕРЕ (в той же вкладке Терминала).

**🔓 СНЯТЬ пароль-замок (утром перед показом):**
```
sed -i.bak 's/^\([[:space:]]*\)auth_basic/\1# auth_basic/' /etc/nginx/sites-available/axon-app
nginx -t && systemctl reload nginx
```
`nginx -t` должен сказать `syntax is ok / test is successful`.
Проверка — на телефоне или на Mac в НОВОЙ вкладке Терминала (не на сервере):
```
curl -s -o /dev/null -w '%{http_code}\n' https://axon-app.ru/ai-studio
```
→ должно быть **НЕ 401** (обычно 200). Значит замок снят, гости проходят.

**🔒 ВЕРНУТЬ пароль-замок (вечером после показа):** та же вкладка на сервере:
```
sed -i.bak 's/^\([[:space:]]*\)#[[:space:]]*auth_basic/\1auth_basic/' /etc/nginx/sites-available/axon-app
nginx -t && systemctl reload nginx
```
Проверка тем же `curl` → должно стать **401**. Замок стоит (`axon`/`1902`).

**Совсем выключить демо-кнопку (когда сезон показов закончится):** на сервере:
```
nano /var/www/axon-app/.env.production
```
Найди строку `NEXT_PUBLIC_DEMO_ENABLED=true`, поменяй `true` → `false`.
Сохранить: `Ctrl+O`, Enter; выйти: `Ctrl+X`. Потом пересборка (5–10 минут):
```
cd /var/www/axon-app && bash deploy.sh
```
Включить обратно — то же самое, только `false` → `true` и снова `bash deploy.sh`.

**Если что-то пошло не так:** `nginx -t` ругается → НИЧЕГО не перезагружай; открой
`nano /etc/nginx/sites-available/axon-app`, найди две строки `auth_basic…` (внутри блока
`location /ai-studio`) и верни как было: `#` в начале строки = замок выключен, без `#` = включён.
Файл пароля `/etc/nginx/.htpasswd` не трогать и не удалять никогда.
Полная версия инструкции — `docs/memory/infrastructure.md`, разделы «ВРЕМЕННЫЙ ПАРОЛЬ» и «Демо-режим».
