## Из Шага 5 (auth)
- ✅ **IDOR / изоляция досок — ЗАКРЫТО на Шаге 7.** Серверные экшены в
  `app/actions/board.ts` (`getBoard / saveBoard / listProjects / createProject /
  deleteProject / renameProject`) берут владельца **только из серверной сессии**
  (`auth.api.getSession`) и проверяют `Board.ownerId === userId`; чужая/несуществующая
  доска → null/false (как 404). Доски разведены по пользователям.
- 🟡 **User-enumeration → Шаг 9.** Сообщения об ошибке входа/регистрации могут выдавать,
  занят ли email. Унифицировать/смягчить.
- 🟡 **Защита входа → Шаг 9.** Rate-limit на `/api/auth/*`, флаги cookie
  (HttpOnly / Secure / SameSite), лимит попыток подбора.
- 🟢 Мелочь: в `BoardSync` сид-сохранение пустой доски для только что вошедшего может не
  сработать с первого раза (сессия ещё «pending») — самокорректируется при следующем изменении.
