# Как выложить сайт на прод (деплой) — шпаргалка

> Простыми словами, для человека. Техничка для разработки — в
> `docs/memory/infrastructure.md`, раздел «Хостинг и деплой».

## Самое главное

Деплой берёт **файлы как они сейчас на твоём Маке** (рабочую папку), а **НЕ из git**.
Значит **коммит делать НЕ обязательно** — что лежит на диске, то и уедет на прод.

Сайт живёт на сервере (Selectel), адрес: **https://axon-app.ru**

## Что нажать — одна команда

В терминале, находясь в корне проекта (папка `axon-app`):

```
./scripts/deploy-remote.sh
```

Всё остальное команда делает сама.

## Что произойдёт (сама команда, по шагам)

1. Зальёт твои файлы на сервер (rsync).
2. На сервере пересоберёт сайт (Docker). **Это несколько минут — это нормально**
   (сервер слабый, 1 ГБ).
3. Применит изменения базы, если они были.
4. В конце напишет `✅ Готово`.

## Где смотреть результат

- Лендинг (главная) → **https://axon-app.ru**
- Сам сервис (приложение) → **https://axon-app.ru/ai-studio**

После деплоя обнови страницу с **Cmd + Shift + R** (свежая загрузка, без кэша).

## Если команда ругается

- Нужен файл **`.env.deploy`** в корне проекта — в нём доступ к серверу
  (IP, пользователь, SSH-ключ). Без него команда не сможет зайти на сервер.
  Этот файл не в git (секрет) — он просто лежит у тебя в папке.
- Если сборка падает по памяти — сервер маленький; обычно помогает повторный запуск
  той же команды (или см. техничку про swap в `docs/backlog.md`).

## Хорошая привычка перед деплоем

Убедиться, что проверка типов чистая (это обычно делает Claude):

```
cd development/apps/landing
npx tsc --noEmit
```

Пусто = всё хорошо, можно деплоить.
