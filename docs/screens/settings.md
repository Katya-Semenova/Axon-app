# Экран: Настройки (личный кабинет)

**URL:** `/settings` (под `basePath` → `/ai-studio/settings`)
**Доступ:** только вошедший. Гость → серверный редирект на `/login` (гейт в `settings/page.tsx`).

Файлы: `settings/page.tsx` (серверный гейт + сессия) + `settings/SettingsForm.tsx` (клиент).
Экран **двуязычный** (`useTranslations("Settings")`, тексты в `messages/*`) — не хардкод.
Действия через Better Auth (`authClient.updateUser / changePassword / signOut / deleteUser`).

---

## Состояния экрана

Экран из независимых блоков-карточек; у каждого свой loading и своё инлайн-сообщение
(ok/err) под блоком.

| Состояние (по блоку) | Условие |
|---|---|
| default | данные подставлены из серверной сессии |
| loading | идёт сохранение конкретного блока (аватар / имя / пароль / удаление) |
| ok | блок сохранён — зелёное сообщение |
| err | ошибка блока — красное сообщение |

## Элементы интерфейса

### Ссылка-карточка «Админка»
- **Видима:** только если `isAdmin` (email ∈ `ADMIN_EMAIL`)
- **При действии:** переход на [`/admin/users`](admin-users.md)

### Блок «Аватар»
- **Элементы:** превью (картинка или инициалы), кнопка «Загрузить», подсказка, сообщение
- **При действии:** выбор файла → POST `/api/avatar` → `updateUser({image})` → обновление
- **Ограничения:** ≤ 2 МБ; типы png / jpeg / webp

### Блок «Профиль»
- **Поле «Имя»** (`autoComplete="name"`), под ним — email (только текст, не редактируется)
- **Кнопка «Сохранить»:** `updateUser({name})`; имя не должно быть пустым

### Блок «Безопасность» (смена пароля)
- **Поля:** «Текущий пароль», «Новый пароль», «Повторите пароль» (все `password`, `required`)
- **Кнопка «Изменить»:** проверка (новый ≥ 8, совпадение) → `changePassword(...)` с
  `revokeOtherSessions: true` (после смены — выход на других устройствах)

### Блок «Выход»
- **Кнопка «Выйти»:** `signOut()` → редирект на `/`

### Блок «Опасная зона» (удаление аккаунта)
- **Поле «Пароль»** (подтверждение), кнопка «Удалить» (destructive)
- **При действии:** браузерный `confirm()` → `deleteUser({password})` → редирект на `/`

## Сообщения

| Ситуация | Тип | Текст (ключ i18n) |
|---|---|---|
| Имя/аватар сохранены | success | «Сохранено» (`saved` / `avatarSaved`) |
| Пароль изменён | success | `changed` |
| Имя пустое | error | `nameRequired` |
| Аватар велик / неверный тип | error | `avatarTooLarge` / `avatarBadType` |
| Новый пароль короткий / не совпал | error | `tooShort` / `mismatch` |
| Неверный текущий пароль | error | `wrongCurrent` |
| Неверный пароль при удалении | error | `wrongPassword` |
| Подтверждение удаления | confirm | `deleteConfirm` (нативный `window.confirm`) |

## Автоматика и уведомления

| Триггер | Канал | Получатель | Текст / Действие |
|---|---|---|---|
| Смена пароля | сессии | сам пользователь | выход на всех др. устройствах (`revokeOtherSessions`) |

## Валидация полей

| Поле | Правило | Сообщение об ошибке |
|---|---|---|
| Аватар (файл) | ≤ 2 МБ; png/jpeg/webp | `avatarTooLarge` / `avatarBadType` |
| Имя | не пусто | `nameRequired` |
| Новый пароль | ≥ 8 символов | `tooShort` |
| Повторите пароль | совпадает с новым | `mismatch` |
| Текущий пароль | верный (проверка бэкенда) | `wrongCurrent` |
| Пароль (удаление) | верный (проверка бэкенда) | `wrongPassword` |
