# Экран: Настройки (`/settings`) — *нужен, нет в коде*

**Доступ:** Пользователь, Admin. Неавторизованный → редирект на [Вход](login.md).

## Состав v1 (согласовано)
1. **Профиль + пароль** — смена пароля (текущий + новый + подтверждение).
2. **Тема** — переключатель светлая/тёмная (опирается на дизайн-систему).
3. **Уведомления** — тумблеры-предпочтения (сохраняются; реальная рассылка писем — позже).

*Удаление аккаунта — отложено (разрушительное, не нужно для v1).*

## Layout
Секции по пунктам выше, кнопка «Сохранить» в секциях, где нужно (тема/тумблеры — авто-применение).

## Данные
Настройки аккаунта — из бэкенда (предпочтения), тема — может храниться и локально.

## Состояния
- **default:** секции.
- **loading/error/success:** на сохранении — тост «Сохранено» / «Ошибка».

## Валидация
- Смена пароля: новый пароль — мин. длина, совпадение с подтверждением, верный текущий пароль.

## Действия
- Сменить пароль → тост.
- Переключить тему → применяется сразу.
- Тумблеры уведомлений → сохраняются.

## Связи
Из меню аватара. Связан с [Профиль](profile.md).

## Визуал

### Layout Desktop
- Контейнер ~640px по центру, `bg-canvas`. Секции — карточки `<Card>` с заголовками (serif): «Профиль + пароль», «Тема», «Уведомления».

### Layout Mobile (≤640px)
- Секции стеком, full-width, padding 16px.

### Компоненты (сверху вниз)
- **Профиль + пароль:** `<FormField>` текущий/новый/подтверждение → `<Input type="password">`; `<Button variant="primary">` «Сохранить».
- **Тема:** переключатель светлая/тёмная — сегмент (`ModeToggle`-паттерн) или `Switch`. **TODO:** `Switch` (atom) в ките нет.
- **Уведомления:** тумблеры-предпочтения → `Switch`. **TODO:** `Switch`.
- Сохранение → `<Toast variant="success">` «Сохранено».

### Визуальные состояния
- **default:** секции. **saving:** `Button loading` → `Toast` success/error.

### Edge cases визуально
- Смена пароля с ошибкой → `<Input invalid>` + текст.
