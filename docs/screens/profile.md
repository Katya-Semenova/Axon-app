# Экран: Профиль (`/profile`) — *нужен, нет в коде*

**Доступ:** Пользователь, Admin (только свой профиль). Неавторизованный → редирект на [Вход](login.md).

## Layout
Данные аккаунта: аватар (инициалы, сейчас статичные «KS»), имя, email. Кнопка «Сохранить».

## Данные
Профиль текущего пользователя — из бэкенда.

## Состояния
- **default:** данные.
- **loading:** загрузка/сохранение.
- **error:** «Не удалось сохранить» + повтор.
- **success:** тост «Сохранено».

## Валидация
- имя — не пусто; email — формат + уникальность.

## Действия
- Редактировать имя/email → «Сохранить» → тост.
- Смена пароля — на экране [Настройки](settings.md) (или здесь — по дизайну; держим в Настройках).

## Связи
Открывается из меню аватара. Связан с [Настройки](settings.md).

## Визуал

### Layout Desktop
- Контейнер ~480px по центру, `<Card>`. Сверху `<Avatar size="lg">` + имя; ниже `<FormField>` имя/email; `<Button>` «Сохранить».

### Layout Mobile (≤640px)
- Full-width карточка, padding 16px.

### Компоненты (сверху вниз)
- `<Avatar size="lg">` (инициалы «KS»).
- `<FormField label="Имя">` → `<Input>`; `<FormField label="Email">` → `<Input type="email">`.
- `<Button variant="primary">` «Сохранить» → `<Toast variant="success">` «Сохранено».

### Визуальные состояния
- **default** / **loading** (`Button loading`) / **error** (`Toast` «Не удалось сохранить») / **success** (`Toast`).

### Edge cases визуально
- Длинное имя/email — скролл внутри поля.
