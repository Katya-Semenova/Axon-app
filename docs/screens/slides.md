# Экран: Presentation / Slides

**Триггер:** workspace, `store.mode="presentation"` (режим **СЛАЙДЫ**). **Доступ:** Гость / Пользователь / Admin.

> Терминология: продукт собирает **презентацию** из **слайдов**. Слово «дека» не используем.
> Три режима воркспейса: **ХОЛСТ** (данные) · **СЛАЙДЫ** (сборка) · **ПОКАЗ** (вывод).

## Принцип: место = скоуп
Где стоит контрол — то он и меняет. Подписи «применяется ко всей презентации» не нужны.
- **Центр** — этот слайд (правится прямо на нём).
- **Правый рельс** — две секции: «ЭТОТ СЛАЙД» и «ВСЯ ПРЕЗЕНТАЦИЯ».
- **Низ** — лента слайдов (набор).

## Layout
- Слева — ChatRail (как в Canvas).
- **Центр — слайд, только редактируемый текст** (заголовок / сводка / заметки докладчика), правится inline по клику. **Контролов-кнопок на самом слайде нет.**
- **Справа — рельс из двух секций по скоупу** (виден, когда слайды есть):
  - **ЭТОТ СЛАЙД** (пер-слайдовое): **Вид** (archetype) и — только при Вид=«График» — **График** (chartType).
  - **ВСЯ ПРЕЗЕНТАЦИЯ** (deck-wide): **Тема** (галерея пресетов + «+ по образцу») и **Заметки** (вкл/выкл).
- **Снизу — лента слайдов** (горизонтальный скролл, drag-сортировка) + кнопка **«+ Слайд»**.

## Два уровня выбора вида (Вид › График)
Вместо одной непонятной кнопки «Chart › …» — два честных уровня:
- **Вид (archetype):** *как показать слайд* — График / Одна цифра / Сравнение / Цитата / Настроение / Список.
  *(Открытые продуктовые решения: судьба «Настроение»/«Список» — переименовать/срезать; язык подписей.)*
- **График (chartType):** появляется **только если** Вид=«График» — Treemap / Donut / Stacked Bar / Lollipop / Map / Scatter / Radar / Heatmap / Dot Matrix / Spline Area.
  *(Открытое решение: подписи плиток — «по смыслу» (доли целого/динамика) vs технические (Treemap/Donut).)*

**ИИ-первый проход:** при создании слайда ИИ сам ставит Вид и График. Пользователь ничего не выбирает на старте — контролы в рельсе нужны только чтобы **переделать** (тихий override).

## Тема (deck-wide)
- **Галерея пресетов** `PRESENTATION_THEMES` — тык по плитке меняет оформление **всей презентации** (шрифты/цвет/радиус через `--slide-*`). Пресеты: Editorial, Soft, **Web-dashboard** (+ ещё Bold / Minimal / Magazine — добавляются).
- **Web-dashboard — тумблер свет/тьма** внутри одной темы (для веб-вывода; согласовано с «Показом → Interactive · dashboard»).
- **«+ по образцу»** — отдельная выделенная кнопка: загрузка картинки (Pinterest) → vision-модель → новая Theme. **Реализация позже, AI-зависимая** (Ярус 3, отдельной сессией после Урока 6) — см. `backlog.md`.

## Данные
Слайды собираются из дата-сетов проекта. Тема презентации (`presentationThemeId`) — состояние проекта.
Слайд рождается из существующего датасета (`addSlideWithDataSet`); новые данные заводятся **на ХОЛСТЕ** через «+ Добавить файл» (файл → ИИ → датасеты). Пустых узлов не создаём.

## Состояния
- **default:** слайд (текст) + рельс из двух секций + лента слайдов.
- **empty:** слайдов нет (`slideOrder` пуст) — подсказка «добавь слайд из данных холста» / «загрузи файл на ХОЛСТЕ»; рельс свёрнут/скрыт.
- **loading/error:** наследуются от загрузки проекта.

## Действия
- **Inline-правка текста** слайда: заголовок, сводка, заметки докладчика — клик, автосейв.
- **Вид / График** (правый рельс, секция «ЭТОТ СЛАЙД») — меняет **только текущий слайд**. Сразу, автосейв.
- **Тема** (правый рельс, секция «ВСЯ ПРЕЗЕНТАЦИЯ») — меняет **всю презентацию**. Сразу, автосейв.
- **Заметки** (вкл/выкл) — показывать ли блок заметок докладчика. *(Открытое решение: судьба Voiceover-режима.)*
- **Лента:** drag-сортировка слайдов; **«+ Слайд»** → пикер датасетов холста, которых ещё **нет** в презентации → выбрал → стал слайдом; **удалить слайд** — крестик на плитке, **с подтверждением** (`<AlertDialog>`).
- text-инсайт, привязанный к датасету слайда, авто-переключает Вид на **Цитата** (видимо пользователю).

## Визуал

### Layout Desktop
- Оболочка `h-screen`, `bg-canvas`. Слева ChatRail (как в Canvas).
- Центр — **слайд** (только inline-текст). Снизу — **лента слайдов** (горизонтальный скролл `.slide-scroll`, drag-сортировка) + «+ Слайд».
- Справа — full-height **рельс из двух секций** (виден, когда `slideOrder` не пуст): «ЭТОТ СЛАЙД» (Вид/График) и «ВСЯ ПРЕЗЕНТАЦИЯ» (Тема/Заметки).
- Все цвета/шрифты — через токены `--slide-*` (тема) и DESIGN.md → UIKit. Хардкод хексов/пикселей на экране запрещён.

### Layout Mobile (≤640px)
- ChatRail скрыт; правый рельс → сворачивается/уходит вниз; лента слайдов — горизонтальный скролл. **TODO:** мобильный layout.

### Компоненты (сверху вниз)
- **ChatRail** — как в Canvas.
- **Слайд** — превью слайда; текстовые зоны редактируются inline.
- **Правый рельс** — две секции; дропдауны Вид/График и плитки тем (паттерн `ChartTypeDropdown`: `surface-raised` + border).
- **Лента слайдов** — карточки-превью, drag-сортировка; «+ Слайд» (пикер) в конце.
- **Удаление слайда** → `<AlertDialog>` подтверждение (есть в ките).

### Визуальные состояния
- **default:** слайд + рельс + лента.
- **empty:** `slideOrder` пуст — подсказка добавить слайд / загрузить файл; рельс скрыт.
- **loading/error:** наследуются от загрузки проекта.

### Edge cases визуально
- Много слайдов — горизонтальный скролл ленты.
- Длинная сводка / заметки — wrap в превью.
- Невидимый текст сводки на тёмной теме — **фикс в рамках рерайта** (хардкод фона `#FAF8F2` → `var(--slide-muted)`).
- Кнопка «Сохранить» не должна лезть на правый рельс — своё место в тулбаре.
