# Экран: Presentation / Slides

**Триггер:** workspace, `store.mode="presentation"`. **Доступ:** Гость / Пользователь / Admin.

## Layout
- Слева — ChatRail (как в Canvas).
- Центр — **редактор слайда** (SlideEditor): архетип (Chart / Big Number / Comparison / Sentiment / Word List / Quote).
- Снизу — **лоток слайдов** с drag-сортировкой.
- Справа — **рейл «Visualization Style»** (темы Editorial/Soft, архетипы, движки рендера). Виден, когда слайды есть.

## Данные
Слайды собираются из дата-сетов проекта. Тема деки (`presentationThemeId`) — состояние проекта.

## Состояния
- **default:** редактор + лоток слайдов.
- **empty:** слайдов нет (`slideOrder` пуст) — в редакторе/лотке подсказка «перетащи дата-сет, чтобы создать слайд»; рейл стиля скрыт.
- **loading/error:** наследуются от загрузки проекта.

## Действия
- Drag-сортировка слайдов в лотке.
- Привязать дата-сет к слайду (drag). Если слайд занят — **добавляем** дата-сет к слайду (не заменяем).
- **Удалить слайд** — кнопка на слайде, **с подтверждением** (модалка «Удалить слайд? Да/Отмена»).
- Рейл «Visualization Style»: смена темы/архетипа/движка — **применяется ко всей деке** (тема) и к выбранному слайду (архетип). Сразу, с автосейвом.
- **Шаблоны деки** (усиление): при создании презентации — выбор шаблона (тема + стартовый набор архетипов). Сменить шаблон можно позже (предупреждение, что перезапишет оформление).
- Редактирование текста слайда (narrative) — инлайн, автосейв.
- text-инсайт, привязанный к дата-сету слайда, авто-переключает архетип на **Quote** (видимо пользователю).

## Связи
Переключение режима ↔ [Canvas](canvas.md) / [Present](present.md). Drill-in [dataset](dataset-drill-in.md) доступен.

## Доступы
Как Canvas: гость работает, сохранение/шаринг — после входа.

## Визуал

### Layout Desktop
- Оболочка `h-screen`, `bg-canvas`. Слева ChatRail (как в Canvas).
- Центр — **SlideEditor** (редактор слайда). Снизу — **лоток слайдов** (горизонтальный скролл `.slide-scroll`, drag-сортировка).
- Справа — full-height **рейл «Visualization Style»** (виден, когда `slideOrder` не пуст): темы Editorial/Soft, архетипы, движки.

### Layout Mobile (≤640px)
- ChatRail скрыт; рейл стиля → сворачивается/уходит вниз; лоток слайдов — горизонтальный скролл. **TODO:** мобильный layout редактора и рейла.

### Компоненты (сверху вниз)
- **ChatRail** — как в Canvas.
- **SlideEditor** — кастом; превью слайда + контролы.
- **Лоток слайдов** — карточки-превью (navy, `rounded-sm`), drag-сортировка.
- **Рейл «Visualization Style»** — дропдауны темы/архетипа/движка (паттерн `ChartTypeDropdown`: `surface-raised` + border).
- **Удаление слайда** → `<AlertDialog>` подтверждение (есть в ките).

### Визуальные состояния
- **default:** редактор + лоток.
- **empty:** `slideOrder` пуст — подсказка «перетащи дата-сет, чтобы создать слайд»; рейл стиля скрыт.
- **loading/error:** наследуются от загрузки проекта.

### Edge cases визуально
- Много слайдов — горизонтальный скролл лотка.
- Длинный narrative — wrap в превью.
