# Экран: Storybook (`/storybook`)

**Доступ:** все (витрина дизайн-системы).

## Layout
Витрина: токены (цвета, типографика, скругления) + компоненты UI-кита.

## Данные
Статичная страница — из дизайн-системы/кода. Внешних данных нет.

## Состояния
Только default (статика). Loading/empty/error не применимы.

## Действия
- Навигация по разделам витрины.
- Ссылка «назад» на лендинг.
- Интерактива (копировать токен и т.п.) в v1 не требуется.

## Связи
Доступен из nav лендинга. В проде — оставляем (или прячем за флаг — решение Урока 3/деплоя).

## Доступы
Публично. Отдельной авторизации не требует.

## Визуал

### Layout Desktop
- 2 колонки: sticky sidebar ~218px (группы TOKENS / COMPONENTS / UI KIT / ORGANISMS; активный пункт — золотая левая граница + `surface-muted`) + main (секции: swatches/preview/code). Фон `bg-canvas`.

### Layout Mobile (≤640px)
- Sidebar сворачивается/над контентом. **TODO:** мобильный layout витрины (сейчас desktop-first).

### Компоненты (сверху вниз)
- Сама витрина: swatches токенов, превью компонентов кита, `CodeBlock` (copy), интерактивные контролы. Инлайн-стили (это инструмент разработчика, не продуктовый экран).

### Визуальные состояния
- Только **default** (статика).

### Edge cases визуально
- Длинный список компонентов — скролл sidebar (`thin-scroll`).
