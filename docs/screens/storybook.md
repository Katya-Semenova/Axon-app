# Экран: Storybook (витрина дизайн-системы)

**URL:** `/storybook` (под `basePath` → `/ai-studio/storybook`)
**Доступ (Урок 7, Задание 12):** на ПРОДЕ — только админ (`ADMIN_EMAIL`, как `/admin`);
гостю и обычному пользователю — `404` (существование страницы не раскрываем, единый паттерн
с админкой). В локальной разработке (`next dev`) — открыт без входа (инструмент разработчика).
Гейт: серверный `storybook/layout.tsx` поверх клиентской витрины `storybook/page.tsx`.

> Внутренняя страница: показывает токены и компоненты UI-кита. Данных пользователя нет
> (утечки нет).

## Состояния экрана

| Состояние | Условие |
|---|---|
| default | статичная витрина: левый навигатор по разделам + демо-секции |

> loading/empty/error не применимы — всё статично, без внешних данных.

## Элементы интерфейса

### Левый навигатор (sticky)
- **Группы:** TOKENS (Surfaces, Navy/Gold ramp, Text, Typography, Radii…) и компоненты кита
- **При действии:** клик по пункту → прокрутка/показ соответствующей секции; активный пункт подсвечен

### Демо-секции компонентов
- Превью каждого компонента кита (Button, Badge, Card, Input, Modal, Toast, DropdownMenu и т.д.)
  в разных состояниях; некоторые интерактивны (можно понажимать)
