# Экран: 404 — Не найдено (`/404`) — *нужен, нет в коде*

**Доступ:** все. Срабатывает на любой несуществующий путь.

## Layout
Заголовок «Страница не найдена», короткий текст, кнопка **«На главную»** → `/`. Оформление — в стиле дизайн-системы.

## Данные
Нет.

## Состояния
Только default.

## Действия
- «На главную» → лендинг.

## Связи
Перехватывает любые битые маршруты (включая попытку зайти в `/admin/*` без прав — см. ниже) или отдельный 403.

## Доступы
Публично. Для `/admin/*` без роли Admin — редирект на 404 (скрываем существование админки) — см. [admin-users](admin-users.md).

## Визуал

### Layout Desktop
- Полноэкранный центрированный блок на `bg-canvas`: крупный «404» (Instrument Serif, display), заголовок «Страница не найдена», текст (Inter, `text-t2`), `<Button variant="primary">` «На главную».

### Layout Mobile (≤640px)
- То же, padding 16px; кнопка `size="lg"`.

### Компоненты (сверху вниз)
- «404» — сериф-дисплей.
- Текст — Inter.
- `<Button variant="primary">` «На главную» → `/`.

### Визуальные состояния
- Только **default**.

### Edge cases визуально
- Нет.
