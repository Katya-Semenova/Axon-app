# Экран: Детали пользователя (`/admin/users/[id]`) — *Admin, нет в коде*

**Доступ:** только **Admin**. Не-admin → редирект на [404](404.md).

## Layout
Профиль пользователя (имя, email, роль, статус, дата) + список его проектов + (опц.) лог последних действий.

## Данные
Аккаунт по `id` + его проекты — из бэкенда.

## Состояния
- **default:** карточка пользователя + проекты.
- **loading/error:** стандартно.
- **empty (проекты):** «У пользователя нет проектов».

## Действия
- **Сменить роль** (Пользователь ↔ Admin) — модалка подтверждения.
- **Заблокировать / разблокировать** — модалка подтверждения.
- **Удалить аккаунт** — разрушительно, модалка с явным подтверждением (каскадно удаляет проекты). В v1 — опционально (можно отложить).
- Открыть проект пользователя — **read-only** (только для модерации), не редактирование.

## Связи
Из [Списка пользователей](admin-users.md).

## Визуал

### Layout Desktop
- Шапка: `<BackButton>` к списку + имя/роль/статус. Ниже — карточка профиля (`<Card>`) + список проектов пользователя + (опц.) лог действий.

### Layout Mobile (≤640px)

### Компоненты (сверху вниз)
- `<BackButton>` → к [Списку](admin-users.md).
- Профиль — `<Avatar>` + поля; роль/статус → `<Badge>`.
- Проекты пользователя — `<ProjectCard>` / строки (read-only).
- Действия: сменить роль / блок / удалить аккаунт → `<Button>` + `<AlertDialog destructive>` подтверждение (удаление каскадно).

### Визуальные состояния
- **default:** карточка + проекты. **loading/error:** стандартно (`<Skeleton>` / сообщение). **empty:** «У пользователя нет проектов».

### Edge cases визуально
- Длинное имя — truncate; много проектов — скролл/пагинация.
