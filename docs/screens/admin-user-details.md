# Экран: Админка — профиль пользователя

**URL:** `/admin/users/[id]` (под `basePath` → `/ai-studio/admin/users/[id]`)
**Доступ:** только админ. Не-админ ИЛИ несуществующий `id` → **404** (`notFound()`).
Серверный рендер, `force-dynamic`.

Файлы: `admin/users/[id]/page.tsx` · данные через server-action `adminGetUser(id)` (под `requireAdmin`).
Вход — клик по пользователю в [списке](admin-users.md). Только просмотр (read-only).

---

## Состояния экрана

| Состояние | Условие |
|---|---|
| default | карточка профиля + список проектов пользователя |
| empty (проекты) | у пользователя нет досок → «У пользователя нет проектов» |
| 404 | не-админ ИЛИ пользователь с таким `id` не найден |

## Элементы интерфейса

### Ссылка «‹ К списку пользователей»
- **При действии:** → [`/admin/users`](admin-users.md)

### Карточка «Профиль»
- **Показывает (только чтение):** имя; Email; «Email подтверждён» (бейдж да/нет);
  Регистрация (дата); число проектов

### Список «Проекты» (доски пользователя)
- **Каждая строка:** название проекта; бейдж «публичная» (если расшарен); дата обновления
- **Пусто:** «У пользователя нет проектов»
- **Только чтение:** открыть/редактировать доску отсюда нельзя

## Сообщения

| Ситуация | Тип | Текст сообщения |
|---|---|---|
| Нет проектов | info | «У пользователя нет проектов» |
| Не-админ / нет пользователя | — | страница 404 |
