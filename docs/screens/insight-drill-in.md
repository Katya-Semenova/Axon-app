# Экран: Инсайт — разворот (drill-in, оверлей)

**Где:** оверлей поверх рабочей области при `expandedInsightId ≠ null` (клик по карточке инсайта).
Это **состояние**, не отдельный URL. **Доступ:** как у воркспейса. Переключатель режимов скрыт, пока открыт.

Файл: `components/canvas/InsightExpandedView.tsx`. **Двуязычный** (`useTranslations("Drill")`).

---

## Состояния экрана

| Состояние | Условие |
|---|---|
| default | содержимое инсайта по его типу (`kind`) |
| data | `kind = data` → редактируемая таблица строк/колонок |
| text / sql / code | просмотр содержимого (текст / SQL / код); имя файла выводится из заголовка |

## Элементы интерфейса

### Шапка
- **«‹ К холсту»** (BackButton) — закрыть разворот (`setExpanded(null)`)
- **Заголовок инсайта** + **бейдж типа** (`kind`: data/text/sql/code)
- **Undo / Redo** (неактивны, если нечего отменять)
- **«Свернуть»** — тоже закрывает разворот

### Тело
- **kind = data:** редактируемая таблица данных инсайта
- **kind = text / sql / code:** просмотр содержимого (моноблок для sql/code, текст для text)

## Открытые вопросы / находки
- **«Связать с дата-сетом» / «Удалить инсайт» / «сменить тип графика» — в этом оверлее не обнаружены**
  (были в старой спеке). Связи между нодами создаются/удаляются **на холсте**; разворот инсайта —
  это просмотр + правка содержимого. Уточнить, нужны ли действия удаления здесь. → проверить/backlog.
- Закрытие подтверждено через «‹ К холсту» / «Свернуть»; закрытие по **Esc / клику вне** — не подтверждено
  (в старой спеке упоминалось) → проверить.
