# Экран: Insight drill-in (оверлей)

**Триггер:** `expandedInsightId` ≠ null (клик по Insight-карточке). Оверлей поверх любого режима. **Доступ:** как родительский воркспейс.

## Layout
Развёрнутый просмотр инсайта поверх холста: заголовок, тип (data/text/sql/code), содержимое (таблица данных / текст / SQL / код), действия. Кнопка «назад/крестик».

## Данные
Один Insight из проекта (`insightsById[id]`). Для data-инсайта — строки/колонки; для text — текст; sql/code — исходник.

## Состояния
- **default:** содержимое инсайта.
- **empty/error:** инсайт пустой или битый — сообщение «нет данных» + предложение удалить/пересоздать.

## Действия
- Закрыть: крестик / **Esc** / клик вне оверлея.
- Редактировать данные/тип графика — сохраняется в проект сразу (есть `updateInsightRows`, `updateInsightChartType`), автосейв.
- **Связать с дата-сетом** прямо отсюда.
- Удалить инсайт (с подтверждением).

## Связи
Открывается из [Canvas](canvas.md) (и поверх Slides/Present). При закрытии — возврат в тот же режим. Пилюля режимов скрыта, пока оверлей открыт.

## Визуал

### Layout Desktop
- Полноэкранный оверлей поверх холста (`absolute inset-0 z-20`, `animate-fade-in`), фон `surface-raised`.
- **Шапка `h-[64px]`** (выровнена с ChatRail): слева `<BackButton>Back to Canvas`, разделитель `|`, серийник `NN /`, заголовок инсайта (truncate), бейдж «N rows · M cols». Справа — контролы (тип графика, undo/redo).
- Тело — содержимое по типу: data → таблица (`DataTable`); text → текст; sql/code → моноблок.

### Layout Mobile (≤640px)
- Оверлей на весь экран; шапка переносит контролы (`flex-wrap`). **TODO:** мобильная компоновка таблицы/контролов.

### Компоненты (сверху вниз)
- **`BackButton`** (кит) → «Back to Canvas».
- Бейдж «N rows · M cols» — паттерн `Chip` (mono, surface-muted). **TODO:** перевести на `<Chip>`.
- **DataTable** (кастом) — строки/колонки.
- Дропдаун типа графика — `ChartTypeDropdown`.
- Удаление инсайта → `<AlertDialog>` подтверждение (есть в ките).

### Визуальные состояния
- **default:** содержимое инсайта.
- **empty/error:** «нет данных» + действие удалить/пересоздать.

### Edge cases визуально
- Длинный заголовок — truncate; широкая таблица — горизонтальный скролл.
