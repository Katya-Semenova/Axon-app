# Экран: Вход (`/login`) — *нужен, нет в коде*

**Доступ:** гость (неавторизованный). Авторизованного — редирект на лендинг/последний проект.

## Layout
Форма: email, пароль. Кнопка «Войти». Ссылки: «Забыли пароль?», «Создать аккаунт». (Соц-вход — позже.)

## Данные
Аутентификация через бэкенд (аккаунты).

## Состояния
- **default:** форма.
- **loading:** кнопка «Войти» в состоянии загрузки.
- **error:** неверные данные → текст под формой «Неверный email или пароль».
- **success:** редирект в продукт (последний проект или лендинг).

## Валидация
- email — формат.
- пароль — не пустой.
- Ошибки полей — под полем, на submit.

## Действия
- «Войти» → проверка → редирект (success) или ошибка.
- «Забыли пароль?» → восстановление пароля (отдельный поток — описать при необходимости; в v1 можно базовый сброс по email).
- «Создать аккаунт» → [Регистрация](signup.md).

## Связи
Попадают из меню аватара и при попытке «Сохранить проект»/шаринга (EC-4).

## Визуал

### Layout Desktop
- Центрированная карточка формы на `bg-canvas`: `<Card>` ~360px по центру (`min-h-screen`, items-center). Сверху — wordmark «AXON» (mono).
- Внутри: заголовок (serif) → `<FormField>` email → `<FormField>` пароль → `<Button variant="primary">` «Войти» (full-width) → ссылки «Забыли пароль?» / «Создать аккаунт».

### Layout Mobile (≤640px)
- Та же карточка, padding 16px, форма full-width. Tap-таргеты ≥44px (кнопка `size="lg"`).

### Компоненты (сверху вниз)
- Wordmark «AXON» (mono-лейбл).
- `<FormField label="Email">` → `<Input type="email" invalid={!!error}>`.
- `<FormField label="Пароль">` → `<Input type="password">`.
- `<Button variant="primary" size="lg" className="w-full">` «Войти» (`loading` при submit).
- «Забыли пароль?» / «Создать аккаунт» → `<Button variant="link">` или `<a>`.

### Визуальные состояния
- **default:** форма. **loading:** кнопка в `loading` (спиннер). **error:** `<Input invalid>` + текст ошибки под формой (`text-error`). **success:** редирект.

### Edge cases визуально
- Длинный email — скролл внутри поля, не ломает layout.
