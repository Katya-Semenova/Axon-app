# Экран: Публичная презентация

**URL:** `/p/[id]` (под `basePath` → `/ai-studio/p/[id]`), `id` = токен ссылки.
**Вид «таб-дашборд» (05.07):** тот же URL с `?view=dashboard` — формат «Web-dashboard ·
Interactive» из Показа; токен общий, отзыв гасит оба вида.
**Доступ:** любой по приватной ссылке, **вход не нужен** (read-only).

Файлы: `p/[id]/page.tsx` (сервер: `getSharedBoard(token)`) + `p/[id]/PublicDeckView.tsx` (клиент).
**Двуязычный** (`useTranslations("Public")`). Слайды рендерит тот же `SlideArchetypeRenderer`,
что и редактор — показ 1-в-1.

---

## Состояния экрана

| Состояние | Условие |
|---|---|
| default | дека валидна → показ слайда + навигация (листание) |
| dashboard | дека валидна + `?view=dashboard` → таб-дашборд: закладки по слайдам вместо листания |
| unavailable | `deck = null` ИЛИ 0 слайдов (токен неверный / отозван / проект удалён) → «Презентация недоступна» |

> Отдельных loading/«generating» состояний в этом экране нет: дека приходит с сервера сразу,
> а невалидный/отозванный токен даёт `deck=null` → экран «недоступна».

## Элементы интерфейса

### Верхняя полоса
- **Логотип «AXON»** — ссылка на `/` · **Счётчик** «текущий / всего» (напр. «2 / 5»)

### Слайд
- Карточка слайда по центру (тема деки): заголовок дата-сета + краткое summary + визуализация
  (архетип/график) — только просмотр, без правки

### Навигация (обычный вид)
- **Кнопка «назад»** (←) — неактивна на первом слайде
- **Кнопка «вперёд»** (→) — неактивна на последнем
- **Точки-прогресс** — клик по точке прыгает на слайд
- **Клавиатура:** стрелки ← / → листают

### Таб-бар дашборда (только `?view=dashboard`)
- Сверху **закладки по слайдам**: название дата-сета слайда или «Слайд N»; активная выделена
- Один слайд на экране, переключение кликом по закладке — без скролла и переходов
- Заменяет навигацию обычного вида (стрелки/точки не показываются)
- Табы стилизуются токенами `--slide-*` выбранной темы деки

### Экран «Презентация недоступна»
- Логотип AXON, заголовок «недоступна» + пояснение, ссылка «На главную» → `/`
