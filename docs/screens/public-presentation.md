# Экран: Публичная презентация (`/p/[id]`) — ✅ *реализовано (Шаг 12)*

> Реализация: серверный `app/p/[id]/page.tsx` грузит деку по токену через
> `getSharedBoard` (app/actions/share.ts), клиентский `PublicDeckView` листает
> слайды и рендерит их `SlideArchetypeRenderer` (read-only). «Сделать копию себе»
> и срок жизни ссылки — в бэклоге; пока ссылка бессрочна до отзыва.

**Доступ:** любой по ссылке (read-only). Вход не требуется.

## Layout
Полноэкранный read-only показ готовой деки: слайды + листание (стрелки ←/→, точки/прогресс). Логотип AXON. Кнопка **«Сделать копию себе»** (для входа/регистрации, если хочет редактировать).

## Данные
Дека проекта по `id` ссылки — из бэкенда. Только публично-расшаренные проекты.

## Состояния
- **default:** слайды деки.
- **loading:** «Загрузка презентации…».
- **error / невалидно:** ссылка недействительна / презентация удалена / доступ отозван владельцем → «Презентация недоступна» + ссылка на лендинг.
- **generating:** если дека ещё собирается — «Презентация ещё готовится».

## Действия
- Листать слайды (←/→, свайп).
- «Сделать копию себе» → вход/регистрация → копия проекта в свой аккаунт.

## Связи
Создаётся из [Build/Present](present.md) → «Поделиться». Владелец может **отозвать** ссылку (revoke) в Build.

## Доступы / безопасность
Доступ только по ссылке-токену. Отзыв ссылки делает её недействительной. Срок жизни — по умолчанию бессрочно до отзыва (уточнить в Уроке безопасности).

## Визуал

### Layout Desktop
- Полноэкранный read-only показ (как Present-режим): слайд по центру, листание стрелками ←/→, точки-прогресс снизу. Логотип «AXON» в углу. Кнопка «Сделать копию себе» top-right.

### Layout Mobile (≤640px)
- Слайд на весь экран, свайп; кнопки крупнее (≥44px).

### Компоненты (сверху вниз)
- Слайд — рендер архетипа (как в Present).
- Навигация — стрелки `<Button size="icon">` + точки-прогресс.
- «Сделать копию себе» → `<Button variant="secondary">` → вход/регистрация.

### Визуальные состояния
- **default:** слайды. **loading:** «Загрузка презентации…» (`<Spinner>`). **error/невалидно:** «Презентация недоступна» + ссылка на главную. **generating:** «ещё готовится».

### Edge cases визуально
- Много слайдов — точки сворачиваются/счётчик; узкий экран — свайп.
