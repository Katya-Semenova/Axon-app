# Экран: Новый пароль (сброс по ссылке)

**URL:** `/reset-password?token=…` (под `basePath` → `/ai-studio/reset-password`)
**Доступ:** гость по токену из письма (ссылка из «Сброса пароля»).

Файл: `development/apps/app/app/reset-password/page.tsx` · Better Auth `resetPassword`.
Токен берётся из query-параметра `?token=`.

---

## Состояния экрана

| Состояние | Условие |
|---|---|
| no-token | в адресе нет `?token=` (ссылка битая/устаревшая) → карточка «Ссылка недействительна» |
| default | токен есть → форма из двух полей пароля |
| loading | идёт сохранение — кнопка в состоянии загрузки |
| error | клиентская проверка не прошла ИЛИ бэкенд отклонил (токен устарел) — текст под формой |
| success | пароль сменён → редирект на `/login` |

## Элементы интерфейса

### Карточка «Ссылка недействительна» (no-token)
- **Видима:** токена нет
- **Текст:** «Ссылка для сброса пароля устарела или неверна. Запросите новую.»
- **Ссылка «Запросить новую ссылку»:** → [`/forgot-password`](forgot-password.md)

### Поле «Новый пароль»
- **Видимо:** есть токен · `type=password`, `autoComplete="new-password"`, `required`

### Поле «Повторите пароль»
- **Видимо:** есть токен · `type=password`, `required`
- *(Намечено к замене на «показать пароль»-глазик вместо второго поля — см. «Находки».)*

### Кнопка «Сохранить пароль»
- **Видима:** есть токен
- **При действии:** проверка (длина ≥ 8, совпадение) → `resetPassword(newPassword, token)` →
  success: редирект на `/login`; error: показать сообщение

### Ссылка «Вернуться ко входу»
- **Видима:** в форме · → [Вход `/login`](login.md)

### Сообщение об ошибке
- **Видимо:** error ≠ null

## Сообщения

| Ситуация | Тип | Текст сообщения |
|---|---|---|
| Пароль короче 8 | error | «Пароль должен быть не короче 8 символов.» |
| Пароли не совпадают | error | «Пароли не совпадают.» |
| Токен устарел / сбой | error | «Не удалось сбросить пароль — возможно, ссылка устарела. Запросите новую.» |
