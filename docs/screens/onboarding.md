# Экран: Onboarding (модалка-знакомство)

**Триггер:** автопоказ при первом визите (флаг `axon_onboarding_done` в localStorage).
Повторно открывается из любого места через `openOnboarding()` (событие).
**Доступ:** все. Файл: `components/ui/OnboardingModal.tsx`. **Двуязычный** (`Onboarding.*`).

---

## Состояния экрана

| Состояние | Условие |
|---|---|
| скрыт | флаг «пройдено» уже стоит И не было ручного вызова |
| открыт: шаг N | показывается; 5 шагов (0…4), у каждого картинка + заголовок + описание |
| последний шаг | кнопка действия меняется на «Начать» |

> Loading/empty/error нет — контент статичный (картинки + тексты из словаря).

## Элементы интерфейса

### Крестик «✕» (закрыть)
- **При действии:** пометить «пройдено» (localStorage) + закрыть

### Картинка + заголовок + описание шага
- **Видимы:** всегда (для текущего шага); тексты — из i18n `steps.N.{title,description,alt}`

### Точки-прогресс (шаги)
- **Кол-во:** 5; активная — шире и золотая
- **При действии:** клик по точке → перейти на этот шаг

### Кнопка «Пропустить»
- **Видима:** на всех шагах, КРОМЕ последнего
- **При действии:** закрыть + пометить «пройдено»

### Кнопка «Далее» / «Начать»
- **«Далее»:** не последний шаг → следующий шаг
- **«Начать»:** последний шаг → закрыть + пометить «пройдено»

### Клик по фону (backdrop)
- **При действии:** закрыть + пометить «пройдено»

## Открытые вопросы / находки
- **Флаг хранится в localStorage** (не в аккаунте). Значит на другом устройстве/после очистки
  кэша тур покажется снова. Для v1 ок; «в профиле» — возможное улучшение.
- **«Назад» в коде нет** (старая спека упоминала) — есть точки + «Далее»/«Пропустить».
- **Кол-во шагов = 5** (картинки `onboarding-1…5`).
