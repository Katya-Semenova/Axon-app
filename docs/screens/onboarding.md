# Экран: Onboarding (модалка)

**Триггер:** первый вход (новый пользователь после регистрации; гостю — при первом открытии воркспейса). Показывается **один раз** — флаг «онбординг пройден» хранится в аккаунте (для гостя — локально). **Доступ:** все.

## Layout
Пошаговая модалка (несколько слайдов) — знакомит с главным сценарием: **загрузил файл → инсайты на холсте → собрал слайды → презентация**. Картинки + короткий текст на шаг.

## Данные
Контент шагов — статичный. Флаг прохождения — в профиле/локально.

## Состояния
- **default:** текущий шаг.
- Без loading/empty/error (статичный контент).

## Действия
- «Далее» / «Назад» — навигация по шагам.
- «Пропустить» и крестик — закрыть и пометить онбординг пройденным.
- На последнем шаге — «Начать» → закрывает, оставляет в воркспейсе/на лендинге.
- Повторный вызов — из меню помощи (опционально, позже).

## Связи
Поверх лендинга/воркспейса. После [Регистрация](signup.md) показывается автоматически.

## Визуал

### Layout Desktop
- Модалка по центру (поверх главной/воркспейса, backdrop navy/40). Картинка шага + короткий текст; снизу — точки-прогресс шагов + кнопки «Назад»/«Далее» (или «Начать» на последнем); крестик «Пропустить».

### Layout Mobile (≤640px)
- Модалка почти на весь экран, картинка сверху, кнопки крупные (≥44px).

### Компоненты (сверху вниз)
- Контейнер — `OnboardingModal` (существующий) на паттерне `Modal` (backdrop + `surface-raised`). **Опц.:** перевести на кит `<Modal>`.
- Картинка шага.
- Точки-прогресс шагов.
- Кнопки «Назад»/«Далее»/«Начать» → `<Button variant="secondary"/"primary">`.
- «Пропустить» / крестик → закрыть + флаг «пройдено».

### Визуальные состояния
- **default:** текущий шаг. Без loading/empty/error (статичный контент).

### Edge cases визуально
- Узкий экран: картинка масштабируется (в коде уже фикс flicker/scaling).
