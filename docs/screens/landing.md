# Экран: Главная приложения / дашборд (`/`)

**Доступ:** все (гость). **Примечание:** это входной экран *внутри приложения* Axon (nav, hero, dropzone, Recent Projects). Маркетинговый **промо-лендинг** — отдельный сайт (https://axon-landing-beige.vercel.app), его детализируем в **Уроке 7**, здесь он не описывается.

## Layout
Nav (AXON · Projects · Storybook · Docs · аватар) · hero · **dropzone загрузки** · секция **«Recent Projects»** (сетка карточек + «View all»).

## Данные
Список проектов пользователя — из бэкенда (сейчас в коде хардкод `PROJECTS`, заменяется на API). Статусы карточек: ready / draft / generating.

## Состояния (Recent Projects)
- **default:** сетка карточек.
- **empty:** проектов нет — текст «Пока нет проектов» + CTA «Загрузить первый файл» (ведёт в dropzone).
- **loading:** скелетоны карточек.
- **error:** «Не удалось загрузить проекты» + «Повторить».

## Действия
- **Dropzone (клик/drop):** создаёт проект, файл уходит на разбор → открывается воркспейс; пока разбор идёт — статус «generating» (EC-3). Копирайт — **два уровня**: «CSV, Excel — полный разбор · PDF, картинки, SQL — приём, разбор в бете» (EC-1). Финальные тексты — Урок 7.
- **Поиск + фильтр/сортировка** проектов (усиление): по имени/дате/статусу. «Ничего не найдено» — пустое состояние с текстом.
- «View all» → отдельный список всех проектов (та же сетка с пагинацией).
- Nav «Projects» → список проектов; «Docs» → справка (в v1 можно заглушка/позже); «Storybook» → `/storybook`.
- **Аватар «KS»** → меню: Профиль · Настройки · Выход (для гостя — «Войти / Регистрация»).
- Клик по карточке проекта → открыть **конкретный** проект по id.

## Связи
→ Воркспейс ([Canvas](canvas.md)), [Storybook](storybook.md), [Профиль](profile.md), [Настройки](settings.md), [Вход](login.md)/[Регистрация](signup.md).

## Доступы
Гость видит лендинг и может загрузить файл; «Сохранить проект» требует вход (EC-4).

## Визуал

### Layout Desktop
- `min-h-screen`, `bg-canvas`, свободный скролл. Контейнер `max-w-screen-xl` по центру, padding 48px (`px-12`).
- **Nav** sticky сверху (`border-b`): wordmark «AXON» (mono) слева; справа ссылки Projects (выкл, `text-t3`) · Storybook (`<a>`) · Docs (выкл) + `<Avatar size="sm">` «KS».
- **Hero** по центру: заголовок Instrument Serif `clamp(40–68px)` с italic-акцентом + подзаголовок Inter.
- **Dropzone** — пунктирная рамка (`border-dashed`), hover/drag → золотая граница (`gold-500`); иконка + копирайт (два уровня форматов, EC-1).
- **«Recent Projects»** — лейбл (mono uppercase) + «View all»; сетка `grid-cols-3` из `<ProjectCard>`.

### Layout Mobile (≤640px)
- Nav-ссылки скрыты (`max-sm:hidden`) — остаётся wordmark + аватар. Бургер-меню НЕ нужно: ссылки nav — инертные лейблы (Projects/Docs ещё не построены), а действия живут в меню аватара (`<DropdownMenu>`). Сетка проектов → 1 колонка. Padding 16px.

### Компоненты (сверху вниз)
- **Nav**: `<Avatar>` (кит); ссылки — `<a>` / inert `<span>`. Меню под аватаром (Профиль/Настройки/Выход) → `<DropdownMenu>` (есть в ките).
- **Hero** — типографика DESIGN.md (display/serif).
- **Dropzone** — кастом (drag-state), токены `border` / `gold-500`.
- **Recent Projects** — `<ProjectCard>` = `<Card variant="interactive">` (4px) + цветной `<Badge>` статуса + `MiniSparkline`.
- **Поиск/фильтр проектов** — `<Input>` + чипы фильтров (`<Chip>`/`<Badge>`). **TODO:** ещё не в коде.

### Визуальные состояния (Recent Projects)
- **default:** сетка карточек.
- **loading:** `<Skeleton>` карточек.
- **empty:** «Пока нет проектов» + CTA «Загрузить первый файл».
- **error:** «Не удалось загрузить» + «Повторить» (`<Button>`).

### Edge cases визуально
- Длинное имя проекта — truncate в карточке; много проектов — «View all» + пагинация.
