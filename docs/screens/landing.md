# Экран: Вход в приложение (входной экран сервиса)

**URL:** `/` сервиса (под `basePath` → `/ai-studio`), вид `view=landing` до открытия воркспейса.
**Доступ:** все (гость + вошедший). Сохранение проекта требует входа.

Файлы: `app/page.tsx` (переключатель `view`), `components/landing/LandingPage.tsx` (экран),
`components/landing/MyProjects.tsx` (проекты вошедшего). **Двуязычный** (`useTranslations("Landing")`).

> Это входной экран **внутри сервиса** (nav, hero, dropzone, «Мои проекты»). Маркетинговый
> промо-лендинг — отдельное приложение `apps/landing` на корне домена (описывается отдельно).

## Состояния экрана

| Состояние | Условие |
|---|---|
| default | nav + hero + dropzone + (вошедший) «Мои проекты» / (гость) приглашение войти |
| dropzone: idle / dragOver / busy | обычный вид / файл тащат над зоной / идёт разбор («Разбираю…») |
| dropzone: error | ошибка разбора — рамка красная + текст (6 видов ошибок) |
| Мои проекты: loading | список ещё грузится — «Загрузка…» |
| Мои проекты: empty | проектов нет — карточка «Пока нет проектов» + CTA создать |
| Мои проекты: filled | сетка карточек проектов |

## Элементы интерфейса

### Навигация (шапка)
- **Wordmark «AXON»** (просто текст)
- **«Projects»**, **«Docs»** — **неактивные заглушки** (`aria-disabled`, серые) — страниц ещё нет
- **«Storybook»** — рабочая ссылка → `/storybook`
- **Переключатель языка** (LanguageSwitcher)
- **AuthNav:** гость → ссылка «Войти»; вошедший → аватар + «Выйти»

### Hero
- Заголовок + подзаголовок (i18n). На узком экране (< lg) — предупреждение, что воркспейс лучше с десктопа

### Dropzone (загрузка файла)
- **Действие:** клик → выбор файла; либо drag-and-drop
- **Принимает:** `.csv .tsv .xlsx .xls .pdf .png .jpg .jpeg .sql .txt .json .svg`
- **Разбор:** CSV/Excel — **полный** (таблица → инсайты → холст); остальные форматы — **beta**
  (просто открывают воркспейс). Гость — разбор по правилам (данные не уходят), холст в памяти,
  без сохранения; вошедший — ИИ-разбор + создание проекта в БД
- **busy:** «Разбираю…», зона неактивна
- **error:** красная рамка + текст ошибки

### «Мои проекты» (только вошедший)
- **Кнопка «+ Новый»:** создать пустой проект → открыть воркспейс
- **Карточка проекта:** заголовок, дата обновления; клик по карточке → открыть проект;
  кнопки **«Переименовать»** (нативный `prompt`) и **«Удалить»** (нативный `confirm`)
- **empty:** карточка «Пока нет проектов» + CTA создать

### Приглашение войти (только гость)
- Вместо проектов — тихая ссылка-приглашение → `/login`

## Сообщения

| Ситуация | Тип | Текст (ключ i18n) |
|---|---|---|
| Файл слишком большой | error | `dropzone.error.tooBig` |
| Файл пустой | error | `dropzone.error.empty` |
| Формат не поддержан | error | `dropzone.error.unsupported` |
| Файл повреждён | error | `dropzone.error.corrupt` |
| Нет колонок | error | `dropzone.error.noColumns` |
| Прочая ошибка разбора | error | `dropzone.error.generic` |
| Идёт разбор | info | `dropzone.parsing` |
| Удаление проекта | confirm | `my.deleteConfirm` (нативный `confirm`) |
| Переименование | prompt | `my.renamePrompt` (нативный `prompt`) |

## Валидация полей

| Поле | Правило | Сообщение об ошибке |
|---|---|---|
| Файл (dropzone) | поддерживаемый формат + успешный разбор | один из `dropzone.error.*` |
| Имя проекта (rename) | не пусто и отличается от старого | (иначе изменение игнорируется) |

## Открытые вопросы / находки
- **«Projects» / «Docs» в nav — заглушки** (страниц нет; намеренно сделаны инертными, не битыми).
- **Поиск / фильтр / сортировка проектов** (были «усилением» в старой спеке) — **в коде НЕТ**.
  Решить: нужны ли (для много проектов) → backlog/продуктовое решение.
- **Переименование/удаление — нативные диалоги** браузера; замена на стилизованные модалки —
  полировка (вне основного потока).
- **i18n здесь сделан.**
