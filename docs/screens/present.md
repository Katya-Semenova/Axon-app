# Экран: Build / Present

**Триггер:** workspace, `store.mode="build"`. **Доступ:** Гость (просмотр/экспорт под вход) / Пользователь / Admin.

## Layout
- Слева — **Build-чат** (живой AI, GigaChat) — собирает деку под аудиторию и тон.
- Центр — гейтвей экспорта + предпросмотр деки.
- Селекторы: **аудитория** (CEO / Board / Team / Investor / Custom) и **тон** (Formal / Neutral / Casual) + режим повествования (narration).
- Лоток дата-сетов скрыт.

## Данные
Дека (slides проекта) + параметры build (audience/tone/narration) — состояние проекта.

## Состояния
- **default:** дека + кнопки экспорта/шаринга/Present.
- **empty:** деки нет — кнопки экспорта/шаринга **задизейблены** + подсказка «сначала собери слайды».
- **loading:** AI собирает деку — стриминг-точки в чате.
- **success:** тост «Готово» после экспорта; тост «Ссылка скопирована» после шаринга.

## Действия
- **Build-чат:** AI помогает пересобрать деку под параметры. **Может действовать** (переставить/переписать слайды) с подтверждением.
- «Custom» аудитория → поле ввода описания аудитории.
- **Экспорт** — кнопка открывает выбор формата: **Ссылка (read-only) · PDF · PPTX · PNG**. PDF/PPTX/PNG — скачивание (тост «Готово»). Ссылка → генерит `/p/[id]`, копирует в буфер (тост «Ссылка скопирована»), можно **отозвать**.
- **Режим показа Present** — полноэкранный показ слайдов: стрелки ←/→, Esc — выход.
- Narration mode — влияет на заметки докладчика в экспорте.

## Связи
Переключение режима ↔ [Canvas](canvas.md) / [Slides](slides.md). Шаринг → [Публичная презентация](public-presentation.md).

## Доступы
Гость может смотреть; экспорт и шаринг требуют вход (EC-4).

## Визуал

### Layout Desktop
- Оболочка `h-screen`, `bg-canvas`. Слева **Build-чат** (ChatRail в build-режиме). Центр — гейтвей экспорта + предпросмотр деки. Лоток скрыт.
- Селекторы **аудитории** и **тона** — сегментированные контролы (паттерн `ModeToggle`, radius 4) или дропдауны.

### Layout Mobile (≤640px)
- ChatRail скрыт; селекторы и кнопки стекаются вертикально. **TODO:** мобильный layout гейтвея.

### Компоненты (сверху вниз)
- **Build ChatRail** — `Textarea` («Refine the presentation…») + send.
- **Селекторы аудитории/тона** — сегменты (`ModeToggle`-паттерн) или дропдауны.
- **Кнопка «Экспорт»** → `Button variant="primary"`; меню форматов **Ссылка · PDF · PPTX · PNG** → `<DropdownMenu>` (есть в ките).
- **Кнопка «Present»** → `Button variant="secondary"`; полноэкранный показ (стрелки ←/→, Esc).
- **Тосты** успех/ошибка → `<Toast>` (semantic; есть в ките).

### Визуальные состояния
- **default:** дека + кнопки.
- **empty:** деки нет — кнопки экспорта/шаринга `disabled` + подсказка.
- **loading:** pulse-dot «AI собирает деку».
- **success:** тост «Готово» / «Ссылка скопирована».

### Edge cases визуально
- Нет слайдов — disabled-состояния кнопок.
- Длинное имя аудитории (Custom) — усечение.
