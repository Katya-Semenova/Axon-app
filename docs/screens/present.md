# Экран: Present (показ) — режим build

**Где:** входной экран `/` → рабочая область, `store.mode = "build"` (это **состояние**, не отдельный URL).
**Доступ:** гость (просмотр; шаринг — после входа) + вошедший.

Файл: `components/build/PresentExport.tsx`. **Двуязычный** (`useTranslations("Export")`).
Показ — это **гейтвей вывода**: выбрать формат → (при ссылке) поделиться. Лоток дата-сетов скрыт.

---

## Состояния экрана

| Состояние | Условие |
|---|---|
| default | заголовок + выбор формата (4 карточки) + пересортировка слайдов + блок действия |
| empty (нет слайдов) | `slideCount = 0` — кнопка «Поделиться» неактивна + подсказка «сначала собери слайды» |
| sharing | идёт создание ссылки — кнопка в состоянии загрузки |
| shared | ссылка создана — показывается URL + «копировать» + «отозвать» |

## Элементы интерфейса

### Шапка
- Ярлык «PRESENT» + счётчик слайдов («слайдов нет» / «N слайдов готовы»); справа — «Войти»/«Сохранить» (гостю); переключатель режимов (на уровне страницы)

### Выбор формата вывода (4 карточки)
- **PPTX**, **PDF**, **View link** (ссылка), **Web-dashboard** (Interactive) — активная отмечена галочкой
- **Реально работают два формата:** «View link» и «Web-dashboard · Interactive» (с 05.07 — та же
  публичная ссылка с `?view=dashboard`, открывается таб-дашбордом). **PPTX / PDF — «скоро»** (заглушки)

### Пересортировка слайдов (DeckReorderTray)
- Финальный порядок слайдов перетаскиванием перед выводом

### Действие (для форматов «View link» и «Web-dashboard · Interactive»)
- **Кнопка «Поделиться»:** неактивна, если 0 слайдов или идёт создание; иначе создаёт публичную
  ссылку `/p/[token]`
- **Web-dashboard использует ТОТ ЖЕ токен**, что и View link; к URL дописывается `?view=dashboard`
  (дека открывается таб-дашбордом — см. [public-presentation](public-presentation.md)). Отзыв гасит обе.
- **После создания:** показ URL, кнопка «копировать», кнопка «отозвать» (делает ссылку недействительной)
- **Гость** жмёт «Поделиться» → окно входа `AuthModal`, затем создаётся ссылка

## Сообщения

| Ситуация | Тип | Текст (ключ i18n) |
|---|---|---|
| Нет слайдов | info | «сначала собери слайды» (кнопка неактивна) |
| Ссылка создаётся | info | `sharing` |
| Ошибка шаринга | error | `shareError` |
| Ссылка отозвана | info | `revoked` |
| PPTX/PDF | info | «скоро» (формат пока не работает) |

## Автоматика и уведомления

| Триггер | Канал | Получатель | Текст / Действие |
|---|---|---|---|
| Создание ссылки | — | владелец | `ShareLink` в БД; URL `/p/[token]` |
| Отзыв ссылки | — | владелец | токен инвалидируется → дека по ссылке «недоступна» |

## Валидация полей

| Поле | Правило | Сообщение об ошибке |
|---|---|---|
| Кнопка «Поделиться» | требуется ≥ 1 слайд | неактивна при 0 слайдов |

## Открытые вопросы / находки
- **Audience / Tone / Narration убраны из Показа** (перенесены в режим Слайды) — старая спека их
  описывала. Сейчас в Показе их нет.
- **Работают ссылка и Web-dashboard (Interactive)** — оба на одном ShareLink-токене (05.07).
  PPTX / PDF — карточки-заглушки «скоро» (другой механизм — генерация файла; экспорт в backlog,
  [ADR-007](decisions/ADR-007-sharing.md)).
- **PNG** из старой спеки — нет; форматы: PPTX / PDF / View link / Web-dashboard (Interactive).
- **Полноэкранный «Present» (←/→, Esc)** из старой спеки — в этом компоненте не обнаружен;
  read-only показ есть для публичной ссылки ([public-presentation](public-presentation.md)).
  Уточнить: нужен ли отдельный in-app полноэкранный показ. → backlog/проверить.
- **Build-чат под аудиторию/тон** убран; слева — обычный ChatRail.
