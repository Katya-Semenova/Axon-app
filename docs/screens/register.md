# Экран: Регистрация

**URL:** `/register` (под `basePath` → `/ai-studio/register`)
**Доступ:** только гость. Вошедший → редирект на `/` *(намерение; в коде не реализовано — см. «Находки»).*

Файл: `development/apps/app/app/register/page.tsx` · регистрация через Better Auth
(`authClient.signUp.email`). Роль по умолчанию — обычный пользователь.

---

## Состояния экрана

| Состояние | Условие |
|---|---|
| default | форма пустая; кнопка «Зарегистрироваться» неактивна (согласие не отмечено) |
| loading | идёт создание аккаунта — кнопка в состоянии загрузки |
| error | бэкенд вернул ошибку (напр. email занят) — текст под формой |
| success | аккаунт создан → редирект на `/` + обновление сессии |

## Элементы интерфейса

### Поле «Имя»
- **Видимо/активно:** всегда (кроме loading) · `autoComplete="name"`, `required`

### Поле «Email»
- **Видимо/активно:** всегда (кроме loading) · `type=email`, `autoComplete="email"`, `required`

### Поле «Пароль»
- **Видимо/активно:** всегда (кроме loading) · `type=password`, `autoComplete="new-password"`, `required`
- **Подсказка под полем:** «Минимум 8 символов»

### Чекбокс согласия
- **Видим:** всегда · `required`
- **Текст:** «Я принимаю Пользовательское соглашение и Политику конфиденциальности»
- **Ссылки:** «Соглашение» → `/terms`, «Политику» → `/privacy` — обычные `<a target="_blank">`
  на корень домена (юр-страницы лендинга); открываются в новой вкладке, форма не теряется
- **При действии:** отметка разблокирует кнопку «Зарегистрироваться»

### Кнопка «Зарегистрироваться»
- **Видима:** всегда
- **Активна:** согласие отмечено И НЕ loading
- **Неактивна:** согласие НЕ отмечено (`disabled`) ИЛИ loading
- **При действии:** `trackEvent(signupStart)` → `signUp.email(name, email, password)` →
  success: `trackEvent(signupComplete)` + редирект на `/`; error: показать сообщение

### Ссылка «Войти»
- **Видима:** всегда
- **При действии:** переход на [Вход `/login`](login.md)

### Сообщение об ошибке
- **Видимо:** error ≠ null · **текст:** сообщение бэкенда ИЛИ «Не удалось зарегистрироваться»

## Сообщения

| Ситуация | Тип | Текст сообщения |
|---|---|---|
| Email уже занят / иная ошибка | error | текст бэкенда (или «Не удалось зарегистрироваться») |
| Поле не заполнено | error | нативная подсказка браузера (`required`) |
| Согласие не отмечено | — | кнопка неактивна (отдельного текста нет) |

## Автоматика и уведомления

| Триггер | Канал | Получатель | Текст / Действие |
|---|---|---|---|
| Начало регистрации (submit) | аналитика | Я.Метрика | цель `signupStart` (no-op без согласия на аналитику) |
| Успешная регистрация | аналитика | Я.Метрика | цель `signupComplete` |

## Валидация полей

| Поле | Правило | Сообщение об ошибке |
|---|---|---|
| Имя | не пусто (`required`) | нативная подсказка |
| Email | формат email + не пусто; уникальность — на бэкенде | нативная / текст бэкенда |
| Пароль | не пусто; мин. 8 символов (подсказка; проверяет бэкенд) | текст бэкенда |
| Согласие | обязательный чекбокс (`required`) | кнопка неактивна |
