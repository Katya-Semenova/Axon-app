# Экран: Canvas (холст) — режим data

**Где:** входной экран `/` → рабочая область, `store.mode = "data"` (это **состояние**, не отдельный URL).
**Доступ:** гость (без сохранения) + вошедший. Сохранение и AI-чат — только вошедшему.

Файлы: `app/page.tsx` (оболочка `Page2`), `components/canvas/Canvas.tsx` (холст),
`components/chat/ChatRail.tsx` (чат слева), `components/presentation/PresentationStructure.tsx` (лоток снизу).
**Двуязычный** (`useTranslations("Canvas")`). Граф/связи/позиции — состояние проекта (Zustand + БД).

---

## Состояния экрана

| Состояние | Условие |
|---|---|
| default | граф: карточки инсайтов → связи → карточки дата-сетов |
| loading | идёт разбор файла — скелетоны карточек + «Generating…» в чате |
| empty | инсайтов нет (разобрали, но пусто) — пустой холст + подсказка в чате |
| error | разбор файла не удался — плашка ошибки на холсте |

## Элементы интерфейса

### Тулбар (верх, 64px)
- **Слева:** ярлык «CANVAS» + счётчики (сколько инсайтов / дата-сетов)
- **Центр:** переключатель режимов Canvas/Slides/Present (рендерится на уровне страницы; скрыт в drill-in)
- **Справа:** Undo / Redo (кнопки + ⌘Z / ⇧⌘Z; неактивны, если нечего отменять; позиции нод в историю не входят),
  кнопки «Войти»/«Сохранить» (для гостя), «Как это работает» (открывает онбординг)

### Холст (граф)
- **Пан:** тянуть пустое место (или средняя кнопка мыши)
- **Зум:** колесо мыши (0.2–2.5×); кнопки **+ / −** и **«Сбросить вид»** (внизу)
- **Карточка инсайта / дата-сета:** клик → разворот (drill-in: [инсайт](insight-drill-in.md) / [дата-сет](dataset-drill-in.md))

### Связи между нодами
- **Создать:** тянуть от порта одной ноды к другой. Связь **двунаправленная** (инсайт↔дата-сет);
  ноды одного типа — связь не создаётся (no-op)
- **Удалить:** навести на линию связи → кнопка удаления (с подсказкой)
- **Дата-сет → лоток:** перетащить карточку дата-сета в лоток снизу = создать слайд

### ChatRail (слева, во всех режимах)
- **Поле «Ask anything…»** + кнопка отправки; **файл-чипы** (загруженные файлы проекта)
- **«AXON» / «Back»:** возврат на входной экран (предупреждение, если есть несохранённые правки)
- **Гостю чат закрыт** (AI — только вошедшим): клик по полю → инлайн-окно входа `AuthModal`,
  холст не теряется, после входа чат разблокируется

## Сообщения

| Ситуация | Тип | Текст |
|---|---|---|
| Идёт разбор | info | «Generating…» (в чате) |
| Инсайтов не извлеклось | info | подсказка в чате «опиши, что хочешь увидеть» |
| Ошибка разбора файла | error | плашка на холсте (предложить другой файл) |
| Возврат с несохранёнными правками | confirm | предупреждение перед уходом |
| Гость кликает чат / «Сохранить» | gate | окно `AuthModal` (вход/регистрация) |

| Поле | Правило | Сообщение об ошибке |
|---|---|---|
| Перетаскивание связи | валидная пара (инсайт↔дата-сет) | невалидный дроп → без эффекта (no-op) |

## Открытые вопросы / находки
- **«+ New Data Set» с холста убран** (старая спека его упоминала) — снят при рерайте слайдов.
  Создание пустого дата-сета теперь не на холсте; если нужно вернуть — продуктовое решение.
- **Чат — OpenRouter** (не GigaChat, как в старой спеке). Модель — `AI_MODEL` (env).
- **Десктоп-only:** ниже `lg` весь воркспейс закрыт заглушкой `DesktopOnlyNotice` (по решению —
  холст/drag-and-drop рассчитаны на десктоп).
- Insight/DataSet-карточки — инлайн в `Canvas.tsx` (TODO: вынести в переиспользуемые компоненты).
