# Экран: Data / Canvas

**Триггер:** `/` view=workspace, `store.mode="data"`. **Доступ:** Гость (без сохранения) / Пользователь / Admin.

## Layout
- Слева — **ChatRail** (живой AI-чат, GigaChat). Сворачивается в полоску 40px.
- Центр — **холст** (node-граф): Insight-карточки (data/text/sql/code) → Connection → DataSet-карточки (график). Пан/зум, перетаскивание.
- Снизу — **лоток дата-сетов** (PresentationStructure).
- Сверху-справа — пилюля режимов CANVAS/SLIDES/PRESENT (скрыта при открытом drill-in).
- Кнопка **«+ NEW DATA SET»** на холсте.

## Данные
- При загрузке файла **ИИ строит первый срез**: извлекает Insight-карточки (из **реального разбора CSV/Excel**; для PDF/картинок/SQL — упрощённые + бейдж **Beta**) и **сам собирает из них готовые DataSet-узлы** со связями (Connection). Источник — бэкенд проекта.
- Дальше граф редактируемый: пользователь меняет связи и дата-сеты. Граф/позиции/связи — состояние проекта (бэкенд + Zustand на клиенте).

## Состояния
- **default:** граф с карточками.
- **loading:** разбор файла идёт (EC-3) — скелетоны карточек, статус «generating».
- **empty:** файл разобран, инсайтов нет (EC-2) — пустой холст + подсказка в чате «опиши, что хочешь увидеть» / «добавить инсайт вручную».
- **error:** разбор не удался (EC-1) — сообщение на холсте + предложение загрузить другой файл.

## Действия
- **AI-чат (Send):** отправляет вопрос + контекст данных → AI отвечает. **Может действовать** (в v1 — ограниченный набор: «добавить инсайт», «добавить дата-сет») **с подтверждением** перед изменением холста.
- Дата-сеты приходят уже собранными ИИ. Пользователь **переподключает** инсайты: отсоединяет ноду от одного дата-сета и присоединяет к другому (перетаскивание Insight → DataSet создаёт связь, chart обновляется). Невалидный дроп — без эффекта, подсказка.
- **Редактировать дата-сет** — открыть [drill-in дата-сета](dataset-drill-in.md) и поправить (тип графика, настройки, состав).
- Перетащить DataSet → лоток = создать слайд.
- «+ NEW DATA SET» — пустой дата-сет (+ парный слайд).
- Клик по карточке — открыть drill-in ([insight](insight-drill-in.md) / [dataset](dataset-drill-in.md)).
- **Undo/redo** — кнопки в UI + хоткеи ⌘Z/⇧⌘Z (позиции нод в историю не входят — by design).
- ChatRail: «AXON»/«Back» → возврат на лендинг (предупреждение, если есть несохранённые правки).
- Файл-чипы в чате — список загруженных файлов проекта (можно убрать/добавить).

## Связи
Лендинг → (загрузка файла) → Canvas. Переключение режима → [Slides](slides.md) / [Present](present.md). Автосохранение проекта — сквозное (см. spec → Объём v1).

## Доступы
Гость работает, но «Сохранить проект» требует вход (EC-4).

## Визуал

### Layout Desktop
- Оболочка на весь экран `h-screen`, без скролла страницы. Фон — `bg-canvas` (#EDE9E0, «бумага»).
- Слева **ChatRail** 280px (сворачивается в полоску 40px), правая граница `border-border`.
- Центр — **холст** (node-граф, пан/зум, overflow hidden). Сверху-справа плавающая пилюля `ModeTabs` (квадратная, radius 0).
- Снизу — **лоток дата-сетов** (`PresentationStructure`).

### Layout Mobile (<lg / 1024px)
- **Воркспейс десктоп-first by design** (холст + drag-and-drop + AI-чат, как Figma/Miro). Ниже `lg` весь воркспейс перекрывается заглушкой `DesktopOnlyNotice` («Axon рассчитано на десктоп» + возврат к проектам) — НЕ показываем «сжатый» граф. Решение пользователя 2026-06-14. Касается всех режимов (Canvas/Слайды/Build) и drill-in.
- ChatRail скрыт (`hidden lg:flex`); прежний мобильный топ-бар убран (его роль взяла заглушка).

### Компоненты (сверху вниз)
- **ChatRail** (`app/components/chat/ChatRail`) — внутри: `Chip` (файл-чипы), `Textarea` («Ask anything…»), круглая send-кнопка (icon, `rounded-pill`), чат-бабблы (navy, `rounded-sm`).
- **Insight-карточка / DataSet-карточка** — кастомные канвас-ноды (не из кита): фон `insight-card`/`surface`, `border-border`, `rounded-sm`. Beta-инсайт → `Badge variant="beta"`.
- **ModeTabs** (`ui/ModeTabs`) — сегменты CANVAS/SLIDES/PRESENT, radius 0.
- **«+ NEW DATA SET»** — пунктирный drop-слот (не кнопка).
- **Undo/redo** — icon-кнопки в тулбаре.

### Визуальные состояния
- **default:** граф с карточками.
- **loading:** `Skeleton` карточек (системный `.shimmer`) + pulse-dot «Generating insights…» в чате.
- **empty:** пустой холст (бумага) + чат-подсказка (EC-2).
- **error:** плашка на холсте, токен `error` (EC-1).

### Edge cases визуально
- Длинный заголовок карточки — усечение (truncate).
- Много нод — пан/зум, без переполнения (canvas overflow hidden).
