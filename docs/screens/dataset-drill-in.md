# Экран: DataSet drill-in (оверлей)

**Триггер:** `expandedDataSetId` ≠ null (клик по DataSet-карточке). Оверлей. **Доступ:** как родительский воркспейс.

## Layout
Развёрнутый дата-сет: крупный график, таблица данных, **настройки графика** (`DataSetSettings`), список связанных инсайтов. Кнопка «назад/крестик».

## Данные
Один DataSet (`dataSetsById[id]`) + его connections/инсайты. 10 типов графиков: Treemap, Heatmap, Map, Lollipop, Donut, Stacked Bar, Dot Matrix, Scatter, Radar, Spline Area.

## Состояния
- **default:** график + настройки.
- **empty:** нет связей (rows пусто) — пустой график + текст «привяжи инсайт, чтобы построить график».
- **error:** наследуется от проекта.

## Действия
- Закрыть: крестик / Esc / клик вне.
- Сменить тип графика (10 типов) — применяется сразу, автосейв.
- Изменить настройки (`DataSetSettings`) — сразу; **сброс к дефолту** доступен.
- Отвязать инсайт.
- Удалить дата-сет (с подтверждением) — код чистит `dataSetIds` у связанных слайдов; UX: предупредить, что затронет слайды.

## Связи
Открывается из [Canvas](canvas.md) / [Slides](slides.md). Закрытие — возврат в режим.
