# Экран: Дата-сет — разворот (drill-in, оверлей)

**Где:** оверлей поверх рабочей области при `expandedDataSetId ≠ null` (клик по карточке дата-сета).
Это **состояние**, не отдельный URL. **Доступ:** как у воркспейса. Переключатель режимов скрыт, пока открыт.

Файл: `components/canvas/DataSetExpandedView.tsx`. **Двуязычный** (`useTranslations("Drill")`).

---

## Состояния экрана

| Состояние | Условие |
|---|---|
| default | крупный график сверху + редактируемая таблица данных снизу |
| empty | у дата-сета нет строк (`rows.length === 0`) — пустой график |

## Элементы интерфейса

### Шапка
- **«‹ К холсту»** (BackButton) — закрыть разворот (`setExpDataSet(null)`)
- **Заголовок дата-сета**
- **Дропдаун типа графика** (`ChartTypeDropdown`) — сменить тип; применяется сразу (автосейв)

### Тело
- **График** (превью выбранного типа) — сверху
- **Сплиттер** (drag) — менять высоту графика
- **Таблица данных** (снизу) — редактируемая (правка строк → автосейв)

## Сообщения

| Ситуация | Тип | Текст |
|---|---|---|
| Нет данных | info | пустой график (строк нет) |
