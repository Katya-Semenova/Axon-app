# Persistence-check (смоук сервиса) — Урок 4, Шаг 10

**Дата:** 2026-06-17 · **Где:** локально (Neon dev-БД) + лёгкая sanity на проде (axon-app.ru) · **Метод:** Playwright MCP.

## Auth ✅
| Проверка | Результат |
|---|---|
| Регистрация (`smoke-axon@example.com`) | ✅ создан, авто-вход, редирект на `/` |
| Выход | ✅ |
| Гейт приватной страницы: `/settings` без входа | ✅ редирект на `/login` |
| Неверный пароль | ✅ отклонён (401, остаётся на `/login`) |
| Верный вход | ✅ редирект на `/` |

## Валидации ☑️
- Неверные креды отклоняются ✅. Формы `register`/`login` имеют HTML5-валидацию (`required`, `type=email`, пароль ≥ 8). Исчерпывающий клик по каждому полю не делал — негативный auth-кейс покрыт.

## Сохранение (действие → жёсткая перезагрузка → в БД) ✅
| Экран | Результат |
|---|---|
| `/settings`: смена имени → reload | ✅ «Smoke Renamed» сохранилось (читается из БД после перезагрузки) |
| Доски: автосейв вошедшего | ✅ подтверждено в этой сессии — публичная ссылка `/p/[token]` грузила доску из Neon (round-trip через БД); merge файла на холсте тоже персистил |

## Файлы ⚠️ (не в этом проходе)
- Загрузка/отдача аватара через `/api/files` + проверка владельца — сделано и захардено в Шаге 8; в этом смоуке заново не гонял.

## Жизненный цикл аккаунта ✅
- Danger zone → пароль → confirm-диалог → аккаунт удалён (каскад), редирект на `/`. Smoke-данные убраны из dev-БД.

## Прод sanity (axon-app.ru) ✅
- `/p/<невалидный токен>` → «Presentation unavailable» (не 500) → деплой здоров, **миграция `share_link` на проде применилась**, публичный роут работает.
