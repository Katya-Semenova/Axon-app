# Карта экранов Axon

> **Источник правды по МАРШРУТАМ и доступу — [`01-app-map.md`](01-app-map.md)** (+ интерактивная
> [`app-map.html`](app-map.html), Урок 7). Этот файл описывает экраны как **вью-состояния** (что
> показывает каждый экран и как до него добраться) — дополняет карту маршрутов, не дублирует её.
>
> **Обновлено 2026-06-23** по фактическому коду (`development/apps/`). Раньше файл помечал вход/
> регистрацию/настройки/админку как «нужен, нет в коде» — **они уже реализованы и работают**.
>
> **Архитектурная реальность.** Сервис (`apps/app`) живёт на приставке `/ai-studio`
> ([ADR-010](decisions/ADR-010-app-url.md)); адреса ниже даны **без приставки**, как в роутере.
> У сервиса несколько роутов (`/`, `/login`, `/register`, `/forgot-password`, `/reset-password`,
> `/settings`, `/admin/users`, `/admin/users/[id]`, `/p/[id]`, `/storybook`). При этом сам `/` —
> стейт-машина: `view` = landing → workspace; внутри workspace `store.mode` = data / presentation /
> build; drill-in и onboarding — оверлеи. Поэтому «экран» = **состояние-вью**, не обязательно
> отдельный URL. Маркетинговый лендинг — отдельное приложение (`apps/landing`, `axon-app.ru/`).
>
> **Доступа через middleware нет** — гейт стоит на самих серверных страницах (`/settings` → редирект
> гостя на `/login`; `/admin/*` → 404 не-админу). Подробности — в `01-app-map.md`.

## Публичная часть

| Экран (вью) | Маршрут / триггер | Доступ | Что показывает |
|---|---|---|---|
| Главная приложения / дашборд | `/` (view=landing) | все (гость) | nav, hero, dropzone, «Recent Projects». **+поиск и фильтр/сортировка проектов** (усиление). *(Входной экран ВНУТРИ сервиса. Маркетинговый промо-лендинг — отдельное приложение `apps/landing`.)* |
| Storybook | `/storybook` | все (внутреннее) | витрина дизайн-системы: токены + компоненты; не в навигации |
| Публичная презентация | `/p/[id]` | все по ссылке | read-only показ готовой презентации по токену шаринга, вход не нужен |
| Вход | `/login` | гость | форма входа (Better Auth) |
| Регистрация | `/register` | гость | форма регистрации + чекбокс согласия |
| Запрос сброса пароля | `/forgot-password` | гость | ввод email → письмо со ссылкой |
| Новый пароль | `/reset-password` | гость по токену из письма | установка нового пароля |
| 404 | стандартная страница Next | все | «не найдено» (кастомной страницы пока нет) |

## Рабочая область (workspace; гостю доступна, сохранение — после входа)

| Экран (вью) | Маршрут / триггер | Доступ | Что показывает |
|---|---|---|---|
| Data / Canvas | view=workspace · `mode="data"` | все | node-граф Insight → Connection → DataSet; слева ChatRail; снизу лоток дата-сетов |
| Presentation / Slides | `mode="presentation"` | все | редактор слайдов, лоток с сортировкой, рейл «Visualization Style» (темы / архетипы / движки). **+шаблоны презентации** при создании (усиление) |
| Build / Present | `mode="build"` | все | гейтвей экспорта: чат-сборка презентации под аудиторию + тон, экспорт, режим показа Present. **+шаринг по ссылке** (усиление) |
| Insight drill-in | оверлей (expandedInsightId) | все | развёрнутый просмотр инсайта поверх любого режима |
| DataSet drill-in | оверлей (expandedDataSetId) | все | развёрнутый дата-сет + настройки графика |

## Личный кабинет (роли: Гость / Пользователь / Admin)

| Экран (вью) | Маршрут / триггер | Доступ | Что показывает |
|---|---|---|---|
| Настройки (профиль + аккаунт) | `/settings` | Пользователь, Admin | имя, пароль, аватар, удаление, выход; вход в админку (если админ). Гость → редирект на `/login`. *(Отдельного `/profile` нет — профиль внутри настроек.)* |

## Админка (роль Admin)

| Экран (вью) | Маршрут / триггер | Доступ | Что показывает |
|---|---|---|---|
| Список пользователей | `/admin/users` | Admin | сводка + список аккаунтов + поиск (read-only, v1). Не-админ → 404 |
| Детали пользователя | `/admin/users/[id]` | Admin | профиль пользователя + его доски (read-only). Не-админ → 404 |

> Админ определяется по env `ADMIN_EMAIL` (один владелец). Роль в БД (`User.role`) и действия
> (смена роли / блок) — после Урока 7 (см. [`backlog.md`](backlog.md)).
