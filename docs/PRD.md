# PRD — Axon

> Краткое описание продукта на одну страницу — для партнёров, руководителя, новых людей в команде, а также для себя через несколько месяцев. Источник правды — [`spec.md`](spec.md). Любое изменение продуктовой части → сначала в spec.md, потом перегенерация этого файла.

## Что за продукт
Инструмент, который превращает сырые данные в готовую презентацию: пользователь загружает файл → получает «editorial insight-карточки» на холсте → собирает из них слайды → презентует. Слоган: «Your data, in plain English».

## Какую проблему решает
Превратить сырые данные во внятную презентацию — долго и вручную: надо разобрать данные, понять, что в них важно, и упаковать всё в красивые слайды. Между «есть файл» и «есть что показать» — часы работы.

## Ключевая ценность
Загрузил файл — и ИИ сам быстро достаёт из него инсайты и собирает из них готовые дата-сеты (графики) — готовый первый срез данных. Пользователь при желании правит его сам (переносит инсайты между дата-сетами, редактирует дата-сеты), а затем складывает из нужных слайды и красиво оформляет презентацию. Весь путь от файла до показа проходит **очень быстро**. Суть: ИИ даёт готовое, а пользователь меняет под себя. Отдельно ценится «редакторский», журнальный вид.

## Для кого
Те, кому нужно быстро превратить данные в наглядный показ:
- **Основатели / руководители** — быстро понять данные и показать инвесторам/команде.
- **Аналитики данных** — ускорить превращение выгрузок в визуальные инсайты и отчёты.
- **Консультанты / агентства** — готовить отчёты и презентации клиентам, ценят скорость и вид.
- **Product / маркетинг** — регулярно показывать метрики и результаты экспериментов.

## Главный пользовательский сценарий
Загрузить файл → ИИ извлекает инсайты и собирает из них готовые дата-сеты → пользователь при желании правит (переносит инсайты, редактирует дата-сеты) и выбирает нужные → собирает слайды → выгрузить/показать презентацию.

## Основные действия в продукте
- **Загрузка файла** на главной приложения → создаётся проект; ИИ извлекает Insight-карточки и собирает из них готовые дата-сеты (первый срез).
- **Data / Canvas** — холст-граф: инсайты → связи → дата-сеты, построенные ИИ; пользователь переподключает ноды и редактирует дата-сеты. Сбоку живой AI-чат; drill-in для инсайтов и дата-сетов.
- **Presentation / Slides** — слайды из дата-сетов: архетипы, лоток с сортировкой, темы (Editorial / Soft), шаблоны деки.
- **Build / Present** — сборка деки под аудиторию (CEO / Board / Team / Investor / Custom) и тон; экспорт (ссылка / PDF / PPTX / PNG) и режим показа.
- **Recent Projects** — дашборд недавних проектов со статусами (ready / draft / generating), поиск и фильтр.
- **Storybook** — витрина дизайн-системы.

## Объём v1 (что реально работает)
Рабочий сквозной демо: реальные аккаунты и сохранение, **реальный разбор CSV/Excel** в графики, живой AI-чат (GigaChat — работает в РФ). PDF/картинки/SQL — принимаем, но инсайты упрощённые (бейдж «Beta»), полный разбор — после v1.

## Платформа
Web, responsive (desktop-first — аудитория работает с данными за компьютером).

## Что НЕ делаем в первой версии (out of scope)
- Реальный разбор PDF / картинок / SQL в инсайты (в v1 принимаем, но инсайты по ним упрощённые).
- Командная работа в реальном времени.
