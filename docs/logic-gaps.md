## Закрытие остатка — дефолты (Шаг 5, режим «дефолты + точечные вопросы»)

Согласовано: фундаментальные развилки закрыты вопросами (роли, бэкенд, разбор файлов, AI-провайдер, экспорт, мощь чата, состав Настроек). Остальные мелкие пробелы закрыты **разумными дефолтами**, и логика каждого экрана записана в `docs/screens/<url>.md`. Принятые дефолты:

- **Тосты/уведомления:** показываем на ключевые события (сохранено, экспортировано, ссылка скопирована, ошибка) — короткий тост с крестиком, авто-скрытие ~3–4 с. (см. spec → Уведомления).
- **Автосейв:** дебаунс после изменения, индикатор «Сохранено / Сохраняю…» в шапке воркспейса.
- **История версий:** автоснимки проекта; панель версий, откат — копией (не перезаписью).
- **Пустые/loading/error** прописаны в каждом файле экрана с данными.
- **Лендинг:** «View all» → список всех проектов с пагинацией; Projects/Docs — включаем (Docs можно заглушкой); меню аватара (Профиль/Настройки/Выход или Войти).
- **Доступы `/admin/*`:** не-admin → редирект на 404 (скрываем админку).
- **Чат:** живой (GigaChat), **может действовать** на холсте — в v1 ограниченный набор (добавить инсайт/дата-сет/правка деки) с подтверждением.
- **Экспорт:** Ссылка (read-only) · PDF · PPTX · PNG.
- **Настройки v1:** Профиль+пароль · Тема · Уведомления (тумблеры); удаление аккаунта — позже.

**Все пробелы закрыты** (вопросом или дефолтом), на каждый из 16 экранов карты есть файл `docs/screens/<url>.md`. Готово к Шагу 6 (модель данных) и Шагу 7 (сборка spec).
