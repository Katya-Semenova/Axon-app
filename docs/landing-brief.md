# Бриф лендинга Axon

> Основа для доработки лендинга (Урок 6, Шаг 1). Создан 2026-06-20.
> Лендинг уже существует (`development/apps/landing`) — мы его **дорабатываем** по этому брифу,
> а не строим с нуля. Источники: `docs/PRD.md` («Для кого») + текущий лендинг.

## Сегменты
- **Главный (под него Hero): Аналитики данных.** Самая острая и понятная боль, текущий лендинг
  уже построен вокруг них — редизайн остаётся цельным.
- **Остальные (блок «для кого / сценарии»):**
  - Основатели / руководители — понять данные и показать инвесторам/команде.
  - Консультанты / агентства — готовить отчёты и презентации клиентам.
  - Product / маркетинг — регулярно показывать метрики и результаты экспериментов.

## Главная задача (JTBD) — аналитик
«У меня есть выгрузка — надо быстро превратить её в понятную презентацию, которую не стыдно
показать, и не убить на это полдня».

## Боль / триггер
Часами вручную переформатирую данные в слайды. Это работа не про мышление, а про оформление.
Триггер — дедлайн «нужно к завтрашней встрече».

## Ценность / точка Б
Загрузил файл → ИИ достаёт инсайты и собирает графики → за минуты готовая «редакторская»
презентация. Пользователь остаётся **автором** (правит под себя), а не оформителем.

## Крючок Hero
Текущий: **«From data to story. Without translation.»** — оставляем (сильный, в точку).

## Целевое действие (одно)
**«Try Axon free» → `axon-app.ru`.**

## Возражения (для FAQ)
- «ИИ переврёт мои цифры?» → числа считает код, не ИИ.
- «Это очередной конструктор дашбордов?» → нет, это про презентацию-историю.
- «Мои данные уходят на сторону?» → уходит только схема + выборка, не весь файл.
- «Надо долго учиться?» → загрузил файл — получил результат.

## Тон

сдержанные осмысленные анимации. Цвета бренда — из `@axon/ui` (свести палитру лендинга к общему
источнику в ходе редизайна).

## Секции на редизайн (главная задача Шага 1)

### 1. PROTOTYPE TEASER — рефайн (идею сохранить)
**Что хорошо:** резко меняет ритм после «стандартных» секций, будит внимание — нестандартно, и это
ценно. Идею НЕ трогаем.
**Что чинить:**
- очень крупные жирные шрифты грубоваты и «не родные» — привести к editorial-стилю остального
  лендинга (вероятно serif вместо тяжёлого Inter bold, выверенные размеры/вес);
- непонятная позиция кнопки «Open prototype» — сделать её явным якорем композиции;
- пустовато — собрать композицию плотнее.

### 2. FEATURES — редизайн (скучный/шаблонный)
**Проблемы:** раскладка банальная и заезженная; анимация совсем простая; стоковое фото в тему по
смыслу, но «отдаёт стоковостью»; в целом унылый блок. Референса нет — направления предлагает AI.
**Цель:** сделать блок небанальным и «дорогим», в едином editorial-стиле, с осмысленной анимацией;
фото — либо заменить на реальный UI продукта, либо подать так, чтобы ушла «стоковость».
