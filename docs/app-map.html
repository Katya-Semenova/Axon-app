Выбери экран

Нажми на кружок в схеме слева — здесь появится список, куда с него можно перейти и по какой кнопке/ссылке.

Сервис живёт на basePath /ai-studio — физические адреса маршрутов сервиса идут с этой приставкой (/login → /ai-studio/login). Middleware нет: доступ гейтится на самих серверных страницах.

Глобальные правила доступа

  • Middleware нет — доступ проверяется на серверных страницах и в server-actions.
  • /settings: нет сессии → редирект на /login.
  • /admin/*: не-админ → 404 (notFound). Админ — по env ADMIN_EMAIL.
  • Холст / открыт гостю; сохранение проекта требует входа.
  • /p/[id] — read-only по приватному токену, без входа.
  • Весь сервис — robots: index:false; в поиск попадает только лендинг.

Заметка (смежное): в /register ссылки на /terms и /privacy под basePath резолвятся в /ai-studio/terms, которых в сервисе нет (юр-страницы на лендинге). В backlog.
