# Session Continuity — непрерывность между сессиями

## Принцип
Проект живёт дольше одной сессии AI. Всё важное — в файлах памяти, не в голове модели.

## Старт сессии
1. Прочитать `docs/memory/state.md` + `docs/decisions/INDEX.md` (только их; остальное — по ссылкам).
2. Просмотреть `docs/backlog.md` (верх, «Ближайшие кандидаты») и согласовать приоритет
   с пользователем ДО кода (договорённость 2026-06-2x).
3. `git status` — убедиться, что чисто / увидеть чужие правки параллельного чата.

## Конец сессии / этапа
Запустить скилл **`/save-session`** — он создаёт журнал в `docs/decisions/sessions/`,
обновляет `state.md` и `INDEX.md`. Для мелких правок хватает обычного git-коммита.

## По ходу
- Крупное решение → отдельный ADR в `docs/decisions/` (+ строка в INDEX + тег `IMPL:`).
- Реализована фича → строка в `docs/memory/feature-registry.md`.
- Отложили работу → `docs/backlog.md` (в конец, коммит сразу — файл общий между чатами).
