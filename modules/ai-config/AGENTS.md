# Модуль ai-config — карта

Настройка AI-ассистента и сквозные механизмы: permissions, AGENTS.md-хаб, система памяти (setup/поиск/сохранение сессий), правила проекта, методичка «как оформить свой промт», механика скиллов и поддержка самой библиотеки (init-project, extend-library).

Полный реестр промтов модуля с триггерами «когда звать» — в общем индексе:
`modules/_INDEX.md`, раздел «ai-config». Промт без строки там — «слепой» (AI не найдёт);
проверка: `bash scripts/check-modules-indexed.sh`. Пополнение — скилл `/extend-library`.
