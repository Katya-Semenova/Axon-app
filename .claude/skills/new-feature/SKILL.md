# /new-feature

Прочитай рецепт `docs/prompts/new-feature.md` (в корне проекта Axon) и выполни его
целиком: Часть 1 (интервью → бриф → одобрение) и Часть 2 (сложность → план →
реализация ролями → верификация → итог), со сверкой по `docs/spec.md`.

Если в проекте установлен плагин `/feature-dev` — на Шаге 3 (реализация) можешь
делегировать ему фазы, передав готовый бриф из Части 1.
