# /continual-learning — память проекта из транскриптов

Память обновляет тот же AI, который её наполнял: читаем историю, достаём устойчивое,
мёржим без дублей. Разовые детали сессий НЕ тащим — для них есть журнал sessions/.

## Где транскрипты
- Claude Code: `~/.claude/projects/<слаг-папки-проекта>/*.jsonl` (+ память `memory/`)
- Журнал проекта: `docs/decisions/sessions/*.md` (уже выжимки — начинай с них)
- Codex / Cursor: их папки истории, если использовались

## Шаги
1. **Период.** Спроси, с какой даты собирать (по умолчанию — с последнего прогона
   этого скилла; смотри журнал sessions/).
2. **Сбор.** Пройди журнал сессий за период (транскрипты — только если журнала мало).
   Ищи ПОВТОРЯЮЩЕЕСЯ: правила, которые проговаривались не раз; решения, на которые
   опирались; грабли, на которые наступали повторно.
3. **Фильтр.** Кандидат в память = устойчиво (≥2 раза) · нетривиально (не выводится
   из кода) · применимо дальше. Разовое и очевидное — отбрасывай.
4. **Мёрж без дублей.** Для каждого кандидата проверь, нет ли уже строки в AGENTS.md /
   `docs/rules/` / ADR. Есть похожее — УТОЧНИ существующее, не плоди новое.
   Правило → AGENTS.md или `docs/rules/` (в том же коммите, правило 3 AGENTS.md);
   решение → новый ADR в `docs/decisions/` + строка в INDEX.md.
5. **Отчёт.** Покажи пользователю дифф: что добавлено, что уточнено, что отброшено и почему.
   После добро́ — коммит `docs(memory): continual-learning <дата>`.

## Правила
- Старые ADR задним числом не править — новое решение = новый ADR со ссылкой на старый.
- Личную память Клода (`~/.claude/.../memory/`) не смешивать с памятью проекта (docs/).
