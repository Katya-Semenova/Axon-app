# /orchestrate-local — крупная задача параллельными агентами

Не для каждой задачи: если ветки работы зависят друг от друга — делай последовательно сам.
Порог: ≥2 независимых куска, каждый ≥15 минут работы.

## Шаги
1. **План.** Разбей задачу на независимые ветки; для каждой: цель · файлы-зона ·
   критерий готовности. Покажи план пользователю, получи добро (правило «план перед кодом»).
2. **Зоны без пересечений.** Проверь, что ветки НЕ трогают одни файлы. Пересекаются →
   объедини в одну ветку или выстрой последовательно. Общие файлы (backlog, spec) — только planner.
3. **Запуск.** Каждой ветке — свой сабагент (Task/Agent, в одном сообщении для параллельности).
   В промте сабагента: контекст проекта (CLAUDE.md-правила), зона файлов, критерий готовности,
   формат ответа: «сделано · изменённые файлы · что проверил · вопросы».
4. **Handoff.** Собери ответы; спорное/вопросы — реши сам или подними пользователю.
   При необходимости — второй раунд (verifier-агент на проверку самого рискованного куска).
5. **Сборка.** Сам прогони `npx tsc --noEmit` + тесты, сведи изменения, коммить по пунктам
   (один пункт = один коммит), одно-предложенческие итоги.

## Правила
- Сабагенты НЕ коммитят и НЕ деплоят — это делает planner после проверки.
- Мак не резиновый: не больше 3–4 параллельных агентов (см. историю с dev-серверами).
