# /init-project

Выполни рецепт `modules/ai-config/prompts/init-project.md` (единственный источник правды —
не дублируй его сюда). Фраза пользователя о проекте — вход; дальше по шагам рецепта:
направление → каркас (git, AGENTS.md, память) → маршрут из промтов библиотеки `modules/`
(смотри `modules/_INDEX.md`).
