# /code-review — ревью ветки пятью взглядами

Пять параллельных сабагентов (Task/Agent), каждый смотрит СВОЮ область — потом сводка.

## Параметры (спроси, если не сказано)
1. **Что ревьюим:** дифф текущей ветки против `main` (по умолчанию) или конкретные коммиты/файлы.

## Шаги
1. Собери дифф: `git diff main...HEAD` (+ список файлов `--stat`).
2. Запусти ПАРАЛЛЕЛЬНО пять сабагентов, каждому — дифф и своя линза:
   - **security** — доступ к чужим данным (IDOR), инъекции, секреты, обход входа
     (+ `.claude/claude-security-guidance.md`);
   - **бизнес-логика** — соответствие `docs/spec.md` и паспортам `docs/screens/`, edge cases;
   - **производительность** — N+1, лишние ререндеры, тяжёлые циклы, размер бандла;
   - **архитектура** — слои (DESIGN.md → ui/ → экраны), дубли, связность;
   - **стандарты** — правила `docs/rules/` (хардкод цветов/пикселей, i18n, комментарии).
3. Сведи находки в один отчёт: таблица «приоритет (critical/high/medium/low) · файл:строка ·
   что не так · что сделать». Дубли слей, спорное помечай как вопрос.
4. Ничего не чини сам — отчёт отдай пользователю, фиксы по отдельной команде.

## Примечание
В свежем Claude Code есть встроенный `/code-review` (уровни low…max, ultra в облаке) —
для быстрого прогона можно звать его; этот скилл — курсовой вариант с линзами под НАШ проект.
