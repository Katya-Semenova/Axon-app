# /extend-library

Выполни рецепт `modules/ai-config/prompts/extend-library.md` (единственный источник правды).
Определи сценарий: А — вынести своё; Б — вобрать чужое по ссылке; В — скилл из реестра
skills.sh (`npx skills`). После любого пополнения — `bash scripts/check-modules-indexed.sh`
должен быть зелёным.
