# Реестр скиллов (.claude/skills/)

> Что есть, когда зовётся. Скилл — тонкая обёртка: рецепт живёт в `modules/` или в теле
> скилла; Claude подхватывает скиллы САМ по description (или руками через `/имя`).
> Новый скилл → строка сюда. Слияние чужих скиллов — через `/extend-library` (без дублей).

| Скилл | Когда зовётся | Рецепт |
|---|---|---|
| `/init-project` | старт нового проекта одной фразой | `modules/ai-config/prompts/init-project.md` |
| `/extend-library` | пополнить библиотеку (своё / чужое по ссылке / skills.sh) | `modules/ai-config/prompts/extend-library.md` |
| `/save-session` | конец этапа/сессии — журнал + state + INDEX | в теле скилла |
| `/ux-testing` | пройти критичные пути глазами в браузере (после деплоя, «что-то поехало») | в теле скилла |
| `/new-feature` | «сделай фичу / реализуй / давай обсудим перед реализацией» | в теле скилла |
| `/avoid-ai-writing` | вычитка текстов от AI-штампов (лендинг, копирайт) | в теле скилла |
