# /deslop — убрать AI-следы из ветки

Работаем ТОЛЬКО по диффу (`git diff main...HEAD`) — существующий код вне диффа не трогаем.

## Что ищем и чиним
1. **Комментарии-пересказ**: «// вызываем функцию X», «// возвращаем результат» — удалить.
   Оставляем только комментарии-ПОЧЕМУ (ограничение, неочевидный контракт).
2. **Защитный мусор**: try/catch вокруг внутренних вызовов, которые не кидают;
   проверки `if (!x) return` там, где x гарантирован типом/вызывающим кодом.
3. **Обход типов**: `as any`, `as unknown as`, `@ts-ignore` — заменить честными типами
   или объяснить, почему нельзя (тогда оставить с комментарием-почему).
4. **Стилистика**: имена/идиомы, выбивающиеся из соседнего кода проекта
   (у нас: русские комментарии, токены вместо хардкода — `docs/rules/ui-components-first.md`).
5. **Мёртвое**: неиспользуемые импорты/переменные/функции, добавленные в этой ветке.

## Шаги
1. `git diff main...HEAD --stat` → список файлов; пройди каждый файл диффа.
2. Покажи пользователю список находок ПЕРЕД правкой (файл:строка · что · почему лишнее).
3. После добро́ — правь, затем `npx tsc --noEmit` + тесты (`npm run test` в apps/app).
4. Один коммит `chore(deslop): …` со списком чисток.

## Правила
- Поведение кода меняться НЕ должно — только читаемость. Сомневаешься — не трогай, отметь.
